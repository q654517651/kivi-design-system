## 变量

- 颜色、间距、圆角、字号、行高、透明度、时长都用 `tokens.css` 里的语义变量，不写死，不用原始色（`white/8`、`gray/900` 这类）。只有深色一套主题。画布连线例外。
- Figma 名换 CSS 名：`/` 换成 `-`，前面加 `--`；小数写成横杠（`border/width/1-25` → `--border-width-1-25`）。
- 数值变量用数字命名，不用 xs、sm、xxl；只有 `border/radius/round` 例外。
- 间距、圆角、控件高度只用变量和组件已有的档位，不发明新值。
- 组件外面不再叠透明度：要淡就用组件自己的类型（比如「轻」），不在外面套 opacity。

## 文字

- 界面 13，阅读 14。哪种文字用哪档见「变量 · 文字样式」。字体苹方。

## 颜色和底色

- 看得出的标准：相邻两层（底和填充、默认和悬停、悬停和选中）的对比度不低于 **1.12**（WCAG 对比度算法，我们自己的线，不要求到无障碍的 3:1）。
- 深底、浅底按背景的**亮度**分，不看色值：先把背景叠了的几层合成，算相对亮度（WCAG 算法），**低于 0.015 是深底，0.015 及以上是浅底**。0.015 是固定的分界，不随变量的值变。
- Container 只有两档，按深浅选：
  - 深底用 Light 1：默认 10%（`container-light-1`）、悬停 14%、按下 18%。base（0.0052）、surface（0.0102）、玻璃（#181818 50% 压在 base 上 0.0070）都是深底。对比度：base 上 1.29，玻璃上 1.31，surface 上 1.34。
  - 浅底用 Light 2：默认 6%（`container-light-2`）、悬停 10%、按下 14%。叠在一层 Light 1 上、popup 都是浅底，对比度 1.20。
  - 深底上不用 Light 2。
- 每种状态用这一档对应的颜色：
  - 有常驻底色的（平时就有底；选中、展开、当前页这类一直留着的状态）用这一档的默认：深底 Light 1（10%），浅底 Light 2（6%）。
  - 悬停用这一档的 hover，按下用 pressed，不管平时有没有底：深底 14% / 18%，浅底 10% / 14%。平时没底色的东西（菜单项、日历格、无底下拉、文字按钮、列表行）悬停也是 hover，不用默认色。
- 变量按语义用，不准为了亮度跨语义借用：Container 只有 Light 1、Light 2 两档，每档的默认、hover、pressed 各管各的状态。不拿 hover 当默认、不拿 pressed 当选中，也不为了看清在背景上再叠一层颜色。看不清就换档（Light 1 / Light 2）或改背景变量，不借别的状态的变量。
- 凹下去的用 container-dark；盖在画布上、必须不透明的用 surface。叠加最多两层。
- 品牌色省着用，不大面积铺底。常见的用处：主操作、勾选、开关打开、进度、拖入提示的图标和字。主要按钮（品牌渐变）一屏只放一个。
- IconButton 没有绿色状态：选中是常驻底色，深底上用 Light 1 默认，图标白。
- 入口别灰：工具条、侧栏里没选值的入口和有值的一样亮，不用灰字当占位。

## 布局

- KIVI 是工作站网站，按全屏使用来排版：卡片、格子的列表不写死几列，定一个最小宽度，一排能放几个放几个，屏越宽放得越多（照即梦）。

## 浮层

- 悬浮在页面上的（菜单、下拉、右键、节点工具栏、参数面板、主站输入框）用玻璃：`--color-bg-fill-glass` + `--effect-glass-blur` + 1px `--color-border-subtle`。下面是什么都行。
- 贴在图片、视频上的控件（卡片上的按钮和按钮条、标签、播放器控件）用 on-media，不加描边，只限图片、视频。
- 模态弹窗用 surface，下面一层遮罩。宽度只用 Dialog 的几档。
- Tooltip、Toast 用 popup 实色。
- 浮层都不加投影。
- 浮层离触发元素的距离按出现方式分三档：点开的（菜单、下拉、面板）4；悬停出来的（预览、长文）8；带箭头的 10（箭头 6 + 空 4）。从看得见的边量：挂在面板里的行上（比如技能预览卡）时，从面板外边量。各组件的 `offset` 默认值就是这三档，不另写。
- 悬停预览素材（参考图、附件、标注引用）一律用 `PreviewPopover`，位置、间距、出现时间都一样。

## 按钮

- 按钮一律方的。只有四个专用按钮是圆的：SendButton（Agent 发送）、ConnectorRemove（连线删除）、参考区右下角的小圆加号、缩略图上的删除。IconButton 没有圆形款。
- 缩略图上的删除是右上角的小圆：离边 4，18 的圆，黑 40% + 背景模糊，图标 14；出现时那张的序号隐藏。参考区、附件条、Lora 栏共用一份。
- 占位的地方（空状态、引导、待生成）的按钮一律减弱一档：Button「轻」，文字灰。
- 按钮右边的下拉箭头一律减弱一档，和 Select 的箭头一样用 `--color-text-fill-tertiary`。
- Agent 回复下的推荐按钮用 Button「轻」。
- 先分清「做动作」还是「选值」：做动作用 Button / IconButton；几个值选一个用分段（TabItem）；值多或文字长用 Select；开关立刻生效用 Switch；范围调值用 Slider + NumberInput；多选用 Checkbox；切换整块内容用选项卡；只展示用 Tag。

## 提示

- Tooltip 只写工具名，可以带快捷键，不做解释。
- 要解释、要看长文的用 Popover（说明 / 长文）；能操作的内容放 Popover 面板。
- 只有图标的按钮都配 Tooltip。

## 菜单和选择

- 单选列表（含 Select）的当前项用「选中」底色，不打勾；打勾只给多选，两行的单选例外。
- 能滚的列表最高停在半条上（菜单 7.5 项），最后露半条，一看就知道能滚；不要正好放满整数条。
- 技能没有不能点的状态：不置灰，不出原因浮层。

## 状态

- 可交互的至少画全默认、悬停、按下、禁用；需要时加选中、加载中、错误。
- 生成中不画进度条，进度交给生成中点阵动效。同一页的点阵共用一个方案、一个时钟，节奏一致。
- 生成失败统一写「生成失败，消耗猕猴桃已退回」。

## 动效

- 一律加减速，不用匀速和 CSS 默认 `ease`；只有循环动画（转圈、扫光、流光）用匀速。
- 先按怎么动选缓动（屏幕内移动 ease-in-out，出现 ease-out，消失 ease-in），再按动多远选时长。曲线只从变量里选，不另写 cubic-bezier。
- 跟着一起动的东西和主体用同一个时长。
- 成组展开 400ms 起，每多一张 +10ms，最多 700ms。
- 系统开了「减少动态效果」，生成中用静态扫光。

## 图标

- 图标用 V3：[Hugeicons](https://hugeicons.com/icons) 免费版（圆角描边）缩到 21、线宽 1.6，名字用「图标」页图标表里的名字。缺的从 Hugeicons 补，不用 Lucide 或别的图标库，补法见「图标」页。
- 模型厂 Logo 只用 LobeHub 的原始 Logo（Mono 版），不用图标库仿的，不自己画。

## 组件

- 业务页面用现有组件拼，不为某个页面再造按钮、菜单。
- 不搞特例：缺样子就给通用组件加类型、状态，不在业务组件里单写。
- 同一个东西有一个组件就只用它：结果叠放只用 MediaGroup，悬停预览只用 PreviewPopover，展开收起只用 Collapse。
- 主站 Agent 和画布 Agent 是同一套对话组件，只有产出不同。
- 组件属性命名：样子叫 `variant`，是什么内容（图片 / 视频、成功 / 错误）叫 `type`，生命周期叫 `status`；尺寸写数字（像素）；生成中统一叫 `generating`。
- 改名都进「旧名对照」。
