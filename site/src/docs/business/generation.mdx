### 拖文件进输入框

<Demo stage="base" code={`
() => {
  const [items, setItems] = useState([]);
  const drop = (files) =>
    setItems((list) => {
      let next = list;
      files.forEach((f, i) => {
        const type = f.type.startsWith('video') ? 'video' : f.type.startsWith('audio') ? 'audio' : 'image';
        next = [...next, { id: Date.now() + '-' + i, type, name: referenceName(next, type), src: type === 'image' ? URL.createObjectURL(f) : undefined }];
      });
      return next;
    });
  return (
    <PromptBox
      placeholder="把图片、视频、音频拖到这里，拖别的类型会提示不支持"
      onDropFiles={drop}
      references={<ReferenceStack items={items} onAdd={() => {}} onRemove={(id) => setItems((list) => list.filter((i) => i.id !== id))} />}
    />
  );
}
`} />

## 参数

### PromptBox

外框是玻璃：底 glass `--color-bg-fill-glass` + 背景模糊 32 `--effect-glass-blur`，浮在生成记录上、下面的内容透出来；描边 border-subtle 1，圆角 24 `--border-radius-24`，内边距 16 `--spacing-16`；内容区和工具条间距 12 `--spacing-12`。宽度跟着外面走，最宽 1040；最窄是工具条所有控件按原宽排成一行时的宽度，工具条不折行、控件不压缩，再窄就不缩了，由外面的页面横向滚动。提示词 14 / 22 常规，primary，无底无描边，聚焦也不加描边，最矮 120，随内容长高。工具条高 32，左右两组间距至少 8。其余原生 `<div>` 属性都能传。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `value` | `string` | — | 提示词。传了就是受控，要在 `onChange` 里更新 |
| `defaultValue` | `string` | — | 非受控的初始提示词 |
| `onChange` | `(value: string) => void` | — | 提示词变了触发，参数是新的文字 |
| `placeholder` | `string` | — | 没输入时的占位文字，随模式变，比如「描述你想生成的视频，@ 引用参考素材」 |
| `references` | `ReactNode` | — | 参考区，在提示词左边，间距 24 `--spacing-24`，从顶端对齐：`ReferenceStack`，或首尾帧 `ReferenceFramePair`。不传没有参考区，提示词从最左边开始。展开时浮在提示词上面，被盖住的字由输入框藏起来 |
| `toolbar` | `ReactNode` | — | 工具条左边，间距 6 `--spacing-6`：任务类型、模型、参考方式、参数、其他开关。一般是 `Select variant="plain"`，不折行、控件不压缩 |
| `actions` | `ReactNode` | — | 工具条右边，间距 8 `--spacing-8`：张数 + `GenerateButton` |
| `maxHeight` | `number` | `240` | 提示词最高多高，单位 px，超过就在里面滚动 |
| `onDropFiles` | `(files: File[]) => void` | — | 把文件拖进输入框、放下后触发，参数是通过 `accept` 检查的文件：一般是加进 `references` 的素材（缩略图、上传进度自己管，输入框不存素材）。不传就不接收拖拽。拖进来时整个输入框盖一层 `DropOverlay`；类型不收的显示「不支持这种文件」，不接收，放下后弹 toast（页面上要放一个 `<Toaster />`） |
| `accept` | `string` | `"image/*,video/*,audio/*"` | 收哪些文件，写法同 `<input accept>`。拖的过程中按类型提前判断 |
| `inputRef` | `Ref<HTMLTextAreaElement>` | — | 提示词输入框的 ref，聚焦、选中用 |
| `inputLabel` | `string` | `"提示词"` | 输入框的说明，读屏用 |

工具条里的 Select 无底：高 32，圆角 8，左右 8，13 号字，左图标 16，右箭头 16 tertiary，悬停白 14%（Light 1 hover），展开白 10%。参数把分辨率、比例、时长合成一个 Select，写「720P · 16:9 · 8s」。

### DropOverlay

文件拖到输入框上时的提示：框本身加一圈 1.5 描边（`--color-border-strong`），里面铺遮罩（`--color-bg-fill-mask`，黑 60%），不模糊；正中浮一张 popup 实色小卡（`--color-bg-fill-popup`，圆角 16，内边距 16 / 24），三个 24 的图标（`Image`、`Files`、`Folder`）+ 13 / 20 的字，都是品牌绿（`--color-brand-solid`），间距 12。出现：整层 150ms ease-out 淡入，小卡从 96% 放大；三个图标从中间叠在一起展开，左右两个往外、各歪 12°，中间的往上浮 6，弹簧 400ms（`--motion-ease-spring`），依次晚 40ms。消失：100ms ease-in，图标收回中间。类型不收：描边、图标和字换 danger（`--color-status-danger`）。不挡鼠标。圆角继承所在的框，所以放它的框要 `position: relative`。`PromptBox` 自带；画布 Agent 输入框这类自己拼的框，配合 `useFileDrop`（`hooks/`）用，它给 `dragging`、`rejected`。其余原生 `<div>` 属性都能传。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `active` | `boolean` | `true` | 显示。文件拖到框上时为 `true`，不显示时淡出 |
| `rejected` | `boolean` | `false` | 拖来的类型不收 |
| `text` | `ReactNode` | `"松手上传"` | 收的时候的文字 |
| `rejectedText` | `ReactNode` | `"不支持这种文件"` | 不收的时候的文字 |

### GenerateButton

就是主要类型的 Button：品牌渐变底，on-brand 字，左图标固定 `Kiwi` 20，文字固定是消耗数，间距 4。宽度跟着数字走，最小 64。其余 Button 属性都能传（`variant`、图标除外）。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `cost` | `number` `string` | — | 这次生成消耗的猕猴桃数，必填，写在图标右边 |
| `size` | `28` `32` `36` | `32` | 同按钮：高 28 / 32 / 36 |
| `loading` | `boolean` | `false` | 点了等结果时用：猕猴桃换成转圈，数字和宽度不变，不能点 |
| `disabled` | `boolean` | `false` | 参数不全或正在生成时用 |
| `aria-label` | `string` | `"生成，消耗 N 个猕猴桃"` | 读屏用，N 是 `cost` |

### PromptInput

提示词输入。无底、无内边距，14 / 22；默认 4 行高（88），随字长高，最多 6 行（132），再多滚动；占位文字 `--color-text-fill-placeholder`。表单里的多行输入用 Textarea。其余原生 `<div>` 属性都能传。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `placeholder` | `string` | — | 没输入时的占位文字 |
| `children` | `ReactNode` | — | 开头的内容：文字，中间可以插 MentionChip。只在第一次渲染时用，之后由用户编辑 |

### ParamPicker

参数选择：长得和无底的 Select 一样，点开是参数面板。画布生成面板和主站输入框共用。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `summary` | `ReactNode` | — | 触发器上的参数摘要，比如「720P · 16:9 · 8s」 |
| `children` | `ReactNode` | — | 面板里一块块 `ParamField` |
| `placement` | `DropdownPlacement` | `"bottom-start"` | 面板位置，放不下自己翻到另一边 |
| `open` | `boolean` | — | 面板展开。传了就是受控 |
| `defaultOpen` | `boolean` | `false` | 非受控时一开始是否展开 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开、收起时触发，参数是新的状态 |
| `aria-label` | `string` | `"参数"` | 触发器的说明，读屏用 |

面板 `ParamPanel`：玻璃浮层，宽 368（视频、音频、高级设置都一样），圆角 16、内边距 12、块间距 12。`ParamField`（`label` + 控件）：标题 14 号 secondary，和控件间距 4。滑块右边是 `NumberInput`（带单位，和滑块双向同步，和 LoraSettings 的「Slider + NumberInput」一样；音高这种有负数的 `min` 写负数就能打负号），和滑块间距 12，对齐轨道（高 20）的中线。


### LoraField

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `value` / `defaultValue` / `onChange` | `LoraFieldItem[]` | `[]` | 已选的 Lora。`LoraFieldItem` 是 `{ id, name, cover, weight, triggerWords?, template? }`。改权重、删除时 `onChange` 给新列表；添加不走这里，走 `onAdd` |
| `max` | `number` | `4` | 最多几个。已选满了，添加格隐藏 |
| `onAdd` | `() => void` | — | 点添加格。外面打开 `LoraPicker`，选好后把结果放回 `value` |

一排间距 4（`--spacing-4`）。已选的是 56 见方的 `ReferenceItem`，底部通栏写权重（一位小数）。悬停已选格，延迟 200ms 在上方（`top-start`）弹出 `LoraSettings`（`Popover variant="panel"`），鼠标能挪进去，键盘聚焦也出；悬停或聚焦格子，右上角出删除（右上角离边 4 的 18 小圆，黑 40% + 模糊，同参考区的删除）。添加格是 `AddTile icon="LoraModel" label="Lora"`（见「上传」页）。其余原生 `<div>` 属性都能传。

### LoraSettings

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|

| `triggerWords` | `string` | — | 触发词。不传就不显示这一块。框里一行省略，右边复制按钮，点了复制，图标换成对勾；失败弹 Toast「复制失败」（页面上要放一个 `<Toaster />`） |

宽 234，块间距 12，要放进 `Popover variant="panel"`（内边距 12 由它给）。「触发词」「提示词模版」小标题 12、`--color-text-fill-tertiary`，和下面的框间距 4；框底 `--color-bg-fill-container-light-1`（玻璃是深底），圆角 6，内边距 6，文字 12 / 16、`--color-text-fill-secondary`，复制按钮是 28 的 `IconButton`。权重一行：标签「权重」13 / 20 secondary，`Slider`（不带刻度）撑满，`NumberInput`（`precision={1}`）宽 56，间距 8。其余原生 `<div>` 属性都能传。

### 生成下拉

下面这些是填好选项的生成控件，画布生成面板、主站输入框、Agent 输入框共用，放进 `PromptBox` 的 `toolbar` 和 `actions`。选项（任务、模型、比例、尺寸、背景、音色、张数、Agent 模式、模型分组、字数上限）都在 `kivi/generation/options.ts`，只写这一份；线上的清单是后端下发的，接入时整体换掉。

`TaskSelect`、`RefModeSelect`、`ModelSelect`、`SizeSelect`、`RatioSelect`、`BackgroundSelect`、`VoiceSelect`、`CountSelect`、`AgentModeSelect` 都是填好选项的无底 `Select`（`variant="plain"`）。展开位置不写，默认往下、放不下自己翻上去。`Select` 的属性（`value`、`defaultValue`、`onChange`、`placement`、`disabled`、`aria-label` 等）都能传，传了盖过默认；选项和样式固定，不能传 `options`、`variant`。

| 组件 | 选项 | 默认 |
|---|---|---|
| `TaskSelect` | Agent / 图片生成 / 视频生成 / 音频生成（`TASKS`） | `image` |
| `RefModeSelect` | 全能参考 / 首尾帧 / 视频编辑 / 视频延长（`REF_MODES`） | `omni` |
| `SizeSelect` | 1K / 2K / 4K（`SIZES`） | `2K` |
| `RatioSelect` | 智能 / 1:1 / 1:4 / 4:1 / 2:3 / 3:2 / 16:9 / 9:16 / 3:4 / 4:3 / 9:21，带比例图标（`RATIOS`） | `1:1` |
| `BackgroundSelect` | 不透明背景 / 透明背景（`BACKGROUNDS`） | `opaque` |
| `CountSelect` | x1 / x2 / x4（`COUNTS`） | `1` |
| `AgentModeSelect` | 手动模式（Agent 在每次生成前询问）/ 自动生成（`AGENT_MODES`），两行菜单项 | `manual` |

| 其余 | `SelectProps` | — | 同上，`value`、`onChange` 等透传给 `Select` |

### VideoParams

视频参数：一个 `ParamPicker`，摘要「分辨率 · 比例 · 时长」，面板里是比例（竖排分段，带比例图标）、时长（刻度滑块 4–15 秒，右边 `NumberInput` 带单位 S）、分辨率（720P / 1080P），有 `audio` 时多一个「生成音频」分段。面板里选的值组件自己管。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `audio` | `boolean` | `false` | 有「生成音频」：Seedance、Kling V3 Omni 有。开着时摘要后面跟一个音量图标 |
| 其余 | `ParamPickerProps` | — | 去掉 `summary`、`children`；`placement`、`open` 一套等都能传 |

### AudioParams

音频高级设置：一个 `ParamPicker`，触发器写「高级设置」，面板里是语速（0.5–2x）、音高（−12–12），其余跟着模型变。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `model` | `string` | `"seed-audio-1.0"` | 音频模型的值：`minimax-speech-2.8-hd` 多「情绪」（自动、开心、悲伤、愤怒、害怕、厌恶、惊讶、中性共 8 项）、没有「生成字幕」；`eleven-v4` 多「稳定性」；Seed 和 Eleven 有「生成字幕」。面板里的控件按模型出 |
| 其余 | `ParamPickerProps` | — | 去掉 `summary`、`children` |

### VideoModelControls

视频：模型 + 参考方式 + 参数，模型在前、参考方式在后（画布和主站一样）。只有首尾帧的模型（Veo、Sora、Grok、Vidu、Seedance 1.5，`VIDEO_FIRST_LAST_ONLY`）不出参考方式；Seedance、Kling V3 Omni（`VIDEO_WITH_AUDIO`）参数里多「生成音频」。返回一串并排的控件，没有外壳，`ref` 和其余属性给模型下拉。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `model` | `string` | — | 视频模型的值。传了就是受控；外面要按模型算生成按钮的消耗就传 |
| `defaultModel` | `string` | `"seedance-2.0"` | 非受控时一开始选哪个视频模型 |
| `onModelChange` | `(model: string) => void` | — | 换了模型时触发，参数是新的模型值 |
| `refMode` | `ReactNode` | `<RefModeSelect />` | 参考方式那一格。要跟着切参考区就自己传一个受控的 |

### ImageModelControls

图片：模型 + 分辨率 + 比例；GPT Image 多一个背景。返回一串并排的控件，`ref` 和其余属性给模型下拉。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `model` | `string` | — | 图片模型的值。传了就是受控；外面要按模型算生成按钮的消耗就传 |
| `defaultModel` | `string` | `"gpt-image-2"` | 非受控时一开始选哪个图片模型 |
| `onModelChange` | `(model: string) => void` | — | 换了模型时触发，参数是新的模型值 |

### AudioModelControls

音频：模型 + 音色 + 高级设置，音色和高级设置跟着模型换。没有张数和比例，右边放 `AudioCharCount`。返回一串并排的控件，`ref` 和其余属性给模型下拉。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `model` | `string` | — | 音频模型的值。传了就是受控；外面要拿它算字数上限就传 |
| `onModelChange` | `(model: string) => void` | — | 换了模型时触发，参数是新的模型值 |

### AudioCharCount

音频生成按钮左边的「字数 / 上限」，代替张数。13 / 20，`--color-text-fill-tertiary`，等宽数字。其余原生 `<span>` 属性都能传。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `count` | `number` | `0` | 现在的字数。超过上限字变红（`--color-status-danger`），不挡生成 |
| `model` | `string` | `"seed-audio-1.0"` | 音频模型的值，上限跟着它变（`AUDIO_CHAR_LIMIT`：Seed 3000、MiniMax 10000、Eleven 5000） |

### GenModelPicker

选择模型（模型偏好）：头部「选择模型」+ 分段「图片 / 视频」，点分段平滑滚到那一组，滚动时分段跟着变；行是两行菜单项（Logo 24 + 名字 + 说明），不标选中。宽 320，列表最高 320 自己滚。点一行把模型插进输入框、关面板；同一组已经选了 4 个（`GEN_MODEL_MAX`）时，没选过的行变灰，悬停提示「最多同时选择 4 个图片模型」。模型分组在 `GEN_MODEL_GROUPS`。`ref` 给包住触发器的外壳（同 `Dropdown`）。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `picked` | `string[]` | `[]` | 已经插进输入框的模型（值），用来算每组选满没有 |
| `onPick` | `(model: SelectOption, type: "image" \| "video") => void` | — | 点了一个模型：插进输入框，面板关上 |
| `trigger` | `ReactElement` | 方块图标按钮 `Mdoel` | 触发器。画布 Agent 用默认的，主站 Agent 工具条传一个无底按钮 |
| `placement` | `DropdownPlacement` | `"top-start"` | 面板位置 |
| `open` / `defaultOpen` / `onOpenChange` | `boolean` | `false` | 面板展开（受控 / 非受控 / 回调） |
| 其余 | `DropdownProps` | — | 去掉 `closeOnSelect`、`haspopup` 等面板自己管的 |

### SkillPicker

技能按钮 + 技能面板：向上弹、左对齐，每次打开回到「推荐」、清空搜索。主站 Agent、画布 Agent 共用。组件里不带任何技能，由外面传进来。`ref` 给包住触发器的外壳（同 `Dropdown`）。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `items` | `SkillItem[]` | — | 技能，传给面板 |
| `categories` | `string[]` | — | 分类，传给面板 |
| `onPick` | `(skill: SkillItem) => void` | — | 点了一个技能：插进输入框，面板关上 |
| `onRetry` / `onCreate` / `onImport` / `onViewAll` / `onDetail` | — | — | 传给面板，说明见 `SkillPanel` |
| `open` / `defaultOpen` / `onOpenChange` | `boolean` | `false` | 面板展开（受控 / 非受控 / 回调） |
| `trigger` | `ReactElement` | 图标按钮 `Skill` | 触发器。主站 Agent 工具条传一个无底按钮 |
| `placement` | `DropdownPlacement` | `"top-start"` | 面板位置 |
| 其余 | `DropdownProps` | — | 同 `GenModelPicker` |

### SkillPanel

技能面板本体（不带触发器），模板里直接摆出来看。玻璃浮层，宽 400、高 440，内边距 8，圆角 16，竖排间距 8。头部「技能」+「创建」下拉 +「全部技能」；下面是分类页签（推荐 / 各分类 / 我的）和搜索（搜索时页签换成搜索框，Esc 只关搜索）；列表是两行菜单项，悬停出「详情」，左边出预览卡（`Popover variant="panel"`）；技能没有不能点的状态。其余原生 `<div>` 属性都能传。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `status` | `"ready"` `"loading"` `"failed"` | `"ready"` | 列表的状态：正常 / 加载中 / 加载失败（「点击重试」）。模板摆状态用 |
| `items` | `SkillItem[]` | `[]` | 技能。「推荐」页签显示 `recommended` 的，「我的」显示 `mine` 的，其余按 `category` 分。没有就显示「暂无技能」 |
| `categories` | `string[]` | `[]` | 分类，排在「推荐」后面、「我的」前面 |
| `defaultTab` | `string` | `"recommend"` | 一开始在哪个页签：`recommend`、分类名或 `mine` |
| `defaultSearch` | `string` | — | 一开始就是搜索、搜的字 |
| `onPick` | `(skill: SkillItem) => void` | — | 点了一个技能 |
| `onRetry` | `() => void` | — | 加载失败时点「点击重试」 |
| `onCreate` | `() => void` | — | 点「创建」下拉里的「创建新的技能」，或「我的」空状态里的「创建技能」 |
| `onImport` | `() => void` | — | 点「创建」下拉里的「导入已有技能」 |
| `onViewAll` | `() => void` | — | 点头部的「全部技能」 |
| `onDetail` | `(skill: SkillItem) => void` | — | 点某一行悬停出的「详情」，参数是那个技能 |

`items` 每一项（`SkillItem`）：

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `id` | `string` | — | 唯一标识 |
| `title` | `string` | — | 名字 |
| `description` | `string` | — | 一句话说明，列表里一行省略，悬停预览里看全文 |
| `category` | `string` | — | 分类，要在 `categories` 里 |
| `cover` | `PlaceholderImageName` | `"kiwi-glass"` | 悬停预览的封面（16:9），没有就用占位图 |
| `recommended` | `boolean` | `false` | 推荐的，出现在「推荐」页签 |
| `mine` | `boolean` | `false` | 我创建的，出现在「我的」页签 |
| `public` | `boolean` | `false` | 公开的，只在「我的」里标「公共技能」 |

### AgentControls

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|

| `skillCategories` | `string[]` | — | 技能面板里的分类 |
| `onPickSkill` | `(skill: SkillItem) => void` | — | 点了一个技能 |
