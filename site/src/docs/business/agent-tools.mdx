## 对照表

工具调用组里每一行用 `ProcessRow`，图标传给 `ProcessStep.icon`；做完的汇总行「调用了 N 个工具」用 `Tool`。

| 后端名 | 显示 | 图标 | 怎么显示 |
|---|---|---|---|
| `inputNode` | 输入节点 | `UseCanvas` | 工具组一行 |
| `deleteNode` | 删除节点 | `UseCanvas` | 工具组一行 |
| `createEdge` | 节点连线 | `UseCanvas` | 工具组一行，对象写「A → B」 |
| `deleteEdge` | 删除节点连线 | `UseCanvas` | 工具组一行，对象写「A → B」 |
| `get_workflow_schema` | 查看画布 | `ScanEye` | 工具组一行 |
| `get_workflow_nodes` | 查看画布节点信息 | `ScanEye` | 工具组一行 |
| `understand_workflow_node_content` | 查看节点内容 | `ScanEye` | 工具组一行 |
| `understand_url_content` | 查看链接内容 | `ScanEye` | 工具组一行，对象写素材名，不写网址 |
| `search_knowledge` | 搜索知识库 | `SquareLibrary` | 工具组一行 |
| `remember` | 更新记忆 | `Brain` | 工具组一行，不显示记住了什么 |
| `skill` | 加载技能 | `Skill` | 工具组一行 |
| `lark_cli` | 执行飞书命令 | `Tool` | 工具组一行 |
| `askUser` | 询问中 / 已询问 / 询问 | `Message` | 不进工具组：询问记录 `AskRecord` + 问题面板 `QuestionPanel` |
| `imageGenerationNode`、`imageRemoveBgNode`、`imageEnhanceNode`、`imageCuttingNode` | — | `ImageGeneration` | 不出工具行，只出结果块 |
| `videoGenerationNode`、`videoSeamlessLoopNode`、`videoEnhanceNode`、`videoStitchNode`、`motionControlNode`、`lipSyncNode` | — | `VideoGeneration` | 不出工具行，只出结果块 |
| `textGenerationNode` | — | `Text` | 不出工具行，只出结果块 |
| `audioGenerationNode` | — | `Audio` | 不出工具行，只出结果块 |
| `executeNode` | — | 按执行的节点 | 不出工具行，只出结果块 |
| `save_skill` | — | — | 不出工具行，出技能卡 `SkillCard` |
| `read_skill_file`、`read_lark_cli_skill`、`load_memory`、`list_session_turns`、`read_session_history`、`list_tools`、`submitPlan`、`write_todos` | — | — | 不显示 |

- 对象文字不加「」，颜色已经比动作淡一档。
- 对象是两个节点时写「A → B」，箭头两边空格。
