## 变量

- 透明度的单位不同：Figma 里 `opacity/50` 是 50，代码里 `--opacity-50` 是 0.5。
- 玻璃的背景模糊和阴影是 Figma 的效果样式，不是变量；代码里照样有 `--effect-glass-blur`、`--effect-shadow-spread`。
- 画布连线的代码名 `--g-workflow-line-color-*` 对应 Figma 的 `color/canvas/connector-*`，是照前端现有名字特意留的，不按 `/` 换 `-`。
- 改名的变量先在 variable.less 里加别名（`--旧名: var(--新名)`），旧代码不用马上改；改值的直接改变量值；写死的颜色按表逐步替换；全部换完再删别名。
- 「处理」一列：改名、改值、合并、删掉、留别名（迁移期保留）、研发自定义（不进 V2）；另有新增、改用途、代码不变（Figma 改了名，代码名不变）。
