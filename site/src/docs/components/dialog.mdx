## Dialog

弹窗：要用户处理完才能继续的事，比如确认删除、重命名、选 Lora。

## 参数

### Dialog

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `open` | `boolean` | — | 打开。传了就是受控，在 `onOpenChange` 里改；不想自己管用 `defaultOpen` |
| `defaultOpen` | `boolean` | `false` | 非受控时一开始是否打开 |
| `onOpenChange` | `(open: boolean) => void` | — | 按 Esc、点遮罩、点关闭按钮时传 `false`；底栏按钮自己调 `setOpen(false)` |
| `size` | `400` `560` `800` `1024` `1200` `"full"` | `400` | 宽度。400 确认、重命名；560 单列表单、分步问答；800 阅读详情、带插图的说明；1024 卡片列表、裁剪；1200 编辑器、多栏；`"full"` 铺满窗口、没有圆角。结构、间距都一样。高度跟着内容走，最高到离窗口边 32；超出时描述和内容区一起滚（边缘渐隐 24，跟着滑的方向），顶图、标题栏、底栏不动；分步弹窗固定高度 |
| `title` | `ReactNode` | — | 标题，16 / 24 粗。不传就没有标题栏，关闭按钮也跟着没有（有顶图时关闭在图上，照样有） |
| `media` | `ReactNode` | — | 顶图，放 `<img>` 或 `<video>`，铺满裁切。离弹窗上、左、右边 8，正常高度为 16:9；窗口矮时收缩裁切，给正文和底栏留空间。圆角 8（弹窗圆角 16 减空隙 8），和下面隔 24。有顶图时关闭按钮挪到图的右上角（离边 12），标题栏里不再放 |
| `showClose` | `boolean` | `true` | 关闭按钮，IconButton 32：在标题栏里是文字类型；有顶图时在图上，是浮层类型 |
| `description` | `ReactNode` | — | 描述，14 / 22 secondary，和标题栏间距 8 |
| `children` | `ReactNode` | — | 内容区，放什么都行。和描述一起滚；要自己分栏滚的（固定高度的弹窗），给 `.kv-dialog__body` 写 `overflow: hidden` |
| `footer` | `ReactNode` | — | 底栏，靠右，间距 8。放 36 的 Button：取消次要、确认主要，删除确认用 `danger`；只有一个按钮时去掉取消 |
| `closeOnMaskClick` | `boolean` | `true` | 点遮罩关闭。有表单或没保存内容的写 `false` |
| `closeOnEsc` | `boolean` | `true` | 按 Esc 关闭。二级弹窗开着时先关最上面的 |

内边距 24（`--spacing-24`），区块间距 16（`--spacing-16`），圆角 16（`--border-radius-16`），底色 `--color-bg-fill-surface`，不加描边和阴影。遮罩 `--color-bg-fill-mask`（黑 60%），不模糊。打开期间 `body` 不能滚动（`overflow: hidden`，滚动条那一条宽度用 `padding-right` 补上，页面不跳），关闭、退出动画放完后恢复；多层弹窗最后一个关掉才恢复。打开 300ms 淡入、从 96% 放大，关闭 200ms 淡出。

`className`、`ref` 和其余原生 `<div>` 属性（`style`、`data-*`、`aria-*`）落在弹窗本体上。

`DialogPanel`：只有盒子，没有遮罩和开关，属性同上，没有 `open` 这几个。文档里摆静态示意用，项目里用 `Dialog`。
