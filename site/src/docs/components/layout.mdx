### 无限加载

滚到离底部 200 以内调一次 `onReachEnd`，加载中在底部放一行 `Loading`。

<Demo code={`
() => {
  const [count, setCount] = useState(20);
  const [loading, setLoading] = useState(false);
  const done = count >= 80;
  const loadMore = () => {
    if (loading || done) return;
    setLoading(true);
    setTimeout(() => {
      setCount((n) => n + 20);
      setLoading(false);
    }, 1000);
  };
  return (
    <ScrollArea maxHeight={280} style={{ width: 320 }} onReachEnd={loadMore}>
      {Array.from({ length: count }, (_, i) => (
        <div key={i} style={{ margin: '4px 0', padding: '8px 12px', borderRadius: 8, background: 'var(--color-bg-fill-container-light-2)', fontSize: 13, lineHeight: '20px' }}>
          {i + 1}. 第 {i + 1} 张作品
        </div>
      ))}
      {loading && <Loading style={{ justifyContent: 'center', padding: '12px 0' }}>加载中…</Loading>}
      {done && <div style={{ padding: '12px 0', textAlign: 'center', fontSize: 12, color: 'var(--color-text-fill-tertiary)' }}>已经到底了</div>}
    </ScrollArea>
  );
}
`} />

## 参数

### Divider

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `orientation` | `"horizontal"` `"vertical"` | `"horizontal"` | 方向。横向宽撑满、高 1；竖向宽 1，高度取所在条写的 `--kv-divider-size`，没有条时 16（`--spacing-16`），不加 size 属性：ButtonGroup 32 里是 16，44、56 里是 20 |

颜色 `--color-border`。放在 Menu 里由菜单换成 `--color-border-subtle`，上下留白 4、左右缩进 8。放在 ButtonGroup 里把不同类的按钮隔开，也用在工具条里隔开不同类的控件。`role="separator"`，其余原生 `<div>` 属性都能传。

### List

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `divider` | `boolean` | `false` | 条目之间加 1px 横线，颜色和 Divider 一样（`--color-border`，可用 `--kv-divider-color` 换），不带左右留白 |

`<ul role="list">`，其余原生属性都能传。左右不留边距，由外面的容器给。

### ListItem

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `children` | `ReactNode` | — | 正文，14 / 22 primary，能换行，保留换行符。要编辑的写字符串 |
| `label` | `ReactNode` | — | 小标题，正文上面，12 tertiary，一行省略 |
| `description` | `ReactNode` | — | 说明，正文下面，比如日期，12 tertiary，一行省略 |
| `more` | `ReactNode` | — | 右边的「⋯」（IconButton 28 · 无底灰），点开弹出这里的菜单，一般是编辑、删除。悬停这一条、键盘聚焦、菜单开着时出现，平时透明但占位；触屏一直显示 |
| `moreLabel` | `string` | `"更多"` | 「⋯」的读屏文字 |
| `editing` | `boolean` | — | 编辑中（受控）。正文原地换成 Textarea，框里右下角取消（次要）/ 保存（主要），按钮 28；说明和「⋯」不显示 |
| `defaultEditing` | `boolean` | `false` | 默认是否在编辑（非受控） |
| `onEditingChange` | `(editing: boolean) => void` | — | 进入、退出编辑 |
| `onSave` | `(text: string) => void` | — | 保存，传去掉首尾空格的内容。回车或点「保存」保存，Shift + 回车换行；空的不能保存；Esc 或「取消」退出不保存，不连外层弹窗一起关 |

上下内边距 12，小标题、正文、说明之间 4，「⋯」离正文 8、上下居中。没有悬停底色。`<li>`，其余原生属性都能传。

### Masonry

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `columns` | `number` `{ default: number; [宽度]: number }` | `4` | 列数。传数字是固定列数；传分段按瀑布流自己的宽度换（宽度 ≤ 键时用那个值，比所有键都宽用 `default`），量的是自己不是窗口。发现页最多 4 列：`{ default: 4, 1100: 3, 700: 2, 500: 1 }` |
| `gap` | `number` | `4` | 列和列、上下两格之间的间距，px。发现页用 2 |
| `ratios` | `number[]` | — | 每一格的宽高比（宽 / 高），和子元素一一对应。传了就往当前最矮的那列放，几列底部差不多齐；不传按顺序一列一个轮着放（线上 react-masonry-css 的做法） |

一个子元素一格，格子自己定高度（比如 `aspect-ratio`）。加载更多时往后追加，已经排好的格子不挪列。其余原生 `<div>` 属性都能传。

### Collapse

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `expanded` | `boolean` | — | 展开（受控）。触发行（按钮、箭头）和展开状态由外面写，触发行加 `aria-expanded`、`aria-controls` |
| `distance` | `number` | `0` | 展开后大约多高，按距离取时长：100 以内 200ms，再长 300ms，ease-in-out |
| `gap` | `0` `2` `4` `6` `8` `12` `16` `24` `32` | `0` | 展开后离上面一行的间距，取 `--spacing-N` 的 N，只有间距变量有的档。放在会被收起的这块里，收起后不留空 |
| `collapsedSize` | `number` | — | 收起后还露出多高（px）。不写，收起后整块藏起来；写了是「长文只露前几行」：收起不淡出、不藏，高度压到这个值，超出的裁掉，展开长到内容高。用户消息超过 12 行只露 12 行（264）用它 |

展开时高度从 0 推到内容高、把下面的内容往下推，同时淡入；收起倒着走。收起后藏起来，Tab 不进去。ThinkingBlock、ProcessGroup、AskRecord、MessageFeedback、侧栏分组都用它。其余原生 `<div>` 属性都能传。

### ScrollArea

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `orientation` | `"vertical"` `"horizontal"` `"both"` | `"vertical"` | 纵向 / 横向 / 两个方向。两个方向都有得滚时，两条滚动条各让出角上 12，不叠在一起 |
| `maxHeight` | `number` `string` | — | 最大高度，超过就在里面滚；数字按 px。外面已经定了高度的不用写 |
| `fade` | `boolean` | `false` | 超出的那边渐隐，跟着滑的方向走：往下滑下面渐隐，往上滑上面渐隐，到头换到另一边。渐隐 24，用 mask，不盖底色。只有纵向有 |
| `onReachEnd` | `() => void` | — | 滚到离末尾不到 `reachEndOffset` 时调用，每次「到了」只调一次：滚开到 offset 以外才会再调；加载后内容变长、还停在末尾（比如内容一开始不满一屏）也会再调一次。内容不够长、没有滚动条时挂上就会调一次。两个方向时只看纵向 |
| `reachEndOffset` | `number` | `200` | 离末尾多少 px 算到了 |
| `viewportRef` | `Ref<HTMLDivElement>` | — | 真正在滚的那个 div，要读 `scrollTop`、调 `scrollTo` 时用 |
| `viewportProps` | `HTMLAttributes<HTMLDivElement>` | — | 透传给滚动视口，比如 `onScroll`、`aria-label`、`id`；`className`、`style`、`onScroll` 和组件自己的合并 |

其余原生 `<div>` 属性都能传，`ref` 给最外层。

滑块的样子：
- 平时不显示。滚动时淡入 150ms ease-out，停下 600ms 后淡出 300ms ease-in。
- 鼠标靠近滚动条（离右边、下边 12 以内）也会出来，滑块宽 6 变 8。触摸设备只在滚动时出现。
- 离边 2，最短 24，圆角 `--border-radius-round`。颜色白 20%（`--color-text-fill-disabled`），悬停、拖动白 40%（`--color-text-fill-tertiary`）。
- 能拖；点轨道朝点的那边翻一页（可视高度的 90%）。鼠标在滚动条上滚轮也照常滚。
- 滚轮、触摸、键盘（方向键、空格、PageUp / PageDown）、惯性都是浏览器原生的，组件不接管。系统开了减少动态效果：淡入淡出直接切换，翻页不带滚动动画。
