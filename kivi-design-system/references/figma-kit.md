# 组件库维护

只在编辑 Figma「KIVI UI KIT V2」组件库本身时读：加组件、改变体、改名、整理页面和 Section。用库里的组件做设计、写代码、出原型，不用读这篇。

## 动手前

- 先只读，看清这一页现在的页面、组件、变量，再改。
- 新做的组件、变体、图标，在描述里标「待确认」。设计师确认后才算正式的。

## 页面顺序

页面分五组，组和组之间用 `---` 页面分割线隔开：

| 组 | 页面 |
|---|---|
| 模板 | 模板 · 画布、模板 · 主站、模板 · 画布 Agent、模板 · 通用 |
| 基础 | 变量、图标、占位图 |
| 通用组件 | 按钮、菜单和提示、选择控件、输入控件、弹窗、反馈、选项卡、标签和头像 |
| 业务组件 | 画布、Agent、主站 |
| 不发布 | _源文件 · 图标描边、_文档组件、_模板 · 文档版式 |

- 新加的页放进对应的组。模板页叫「模板 · ××」。
- 脚本挪不动页面：插件移动页面要加载页里所有字体，苹方加载不了会报错。新页建好后，请设计师手动拖到位置。

## 不发布的内容

- 只给组件库自己用的东西（文档组件、源文件、版式模板），名字用 `_` 开头，比如 `_doc/页头`。Figma 发布时会跳过 `_` 开头的组件。
- 文档专用的变量放 `_doc` 集合，集合设成不发布，不和产品变量混在一起。

## 命名

- 组件名用英文大驼峰：Button、IconButton、MenuItem。
- 属性名和属性值用中文：尺寸=小/中/大，状态=默认/悬停/按下/禁用。
- 改组件名、属性名、属性值、变量名、图标名，都要在那一页的「迁移映射」里加一行旧名 → 新名。

## 绑变量

- 颜色、圆角、间距、字号都绑变量，不手填数值。变量见「变量」。
- 文档里的说明块、页头这类非产品界面，用 `_doc` 集合里的变量。

## 图标

照「图标」里「设计：怎么加新图标」做。Agent 不能自己画图标放进 Figma。

## 文档版式

- 页头、Section、文字样式、间距都照「_模板 · 文档版式」页做，动手前先读那一页。底色和间距的具体数值在「07 版式和间距」。
- Section 底色用 `_doc` 集合里的 section-bg，不用 base。base 是组件里用的颜色，混用了分不清。
