## 怎么用

- **前端**：React 18。从 `kivi` 引组件，比如 `import { Button } from '@kivi'`。引一次入口就带上变量和基础样式，每个组件自己带 CSS。
- **设计**：每个组件的属性面板和 Figma 右侧属性一一对应，可以拿来对照效果。
- **AI**：skill 直接读源码：规范在 `src/docs/` 的 `.mdx`，组件在 `src/kivi/` 的 `.tsx` 和 `.css`。不另外维护一份 md。

## 文件

| 位置 | 是什么 | 前端要不要用 |
|---|---|---|
| `src/kivi/tokens.css` | 所有变量。数值只写在这里 | 要 |
| `src/kivi/base.css`、`Icon.tsx`、`icons.ts` | 图标和加载转圈。图标从 Figma 导出 | 要 |
| `src/kivi/按组件类型/` | 按组件类型分文件夹（菜单、导航、输入框、选择……）：组件 `.tsx` + 这一类的 `.css` | 要 |
| `src/docs/` | 规范页面：用途、结构、属性、样子、用法 + 演示 | 不用，看就行 |
| `src/shell/` | 这个网站自己的外壳：目录、演示、属性面板 | 不用 |

## 和 Figma 同步

- 目录按组件类型分，和 `src/kivi/` 的文件夹对应；Figma 的页名和新页的对应看「旧名对照」的「页面改名」。Figma 改了哪个组件，就改对应的页面和 `src/kivi/` 里那个文件夹。
- 改变量：只改 `tokens.css`，页面上的值是从它读出来的。
- 改组件：改组件的 `.tsx`、`.css`，再改页面上的说明。
- 改名要有对照，只放「旧名对照」一页（变量、图标、组件都在这）。

## 本地打开

在 `kivi-design-system/site/` 下：

```bash
npm install
npm run dev
```

打开 `http://localhost:4173/`。内网别的电脑用这台电脑的内网地址加 `:4173`。
