## TabItem

选项卡 / 分段的一项：比如技能分类里的「设计」，比例里的「16:9」。

<TabItemPlayground />

## Tabs

选项卡 / 分段：选项卡切换整块内容，比如技能分类、资产类型；分段在几个值里选一个，比如比例、分辨率。

<Demo code={`
() => {
  const [tab, setTab] = useState('all');
  const TEXT = { all: '全部作品', image: '图片作品', video: '视频作品', fav: '收藏的作品' };
  return (
    <div style={{ display: 'flex', flexDirection: 'column', alignItems: 'flex-start', gap: 'var(--spacing-16)', width: '100%' }}>
      <Tabs size={36} value={tab} onChange={setTab} aria-label="作品类型">

        <TabItem value="image" id="tab-image" aria-controls="works-panel">图片</TabItem>
        <TabItem value="video" id="tab-video" aria-controls="works-panel">视频</TabItem>

      </Tabs>
      <div role="tabpanel" id="works-panel" aria-labelledby={'tab-' + tab} style={{ color: 'var(--color-text-fill-secondary)' }}>

      </div>
    </div>
  );
}

## 参数

### TabItem

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `children` | `ReactNode` | — | 文字。字重常规 400，选中也不加粗。分段被压窄、放不下时末尾省略号、内边距不让，悬停出 Tooltip 看全文 |
| `value` | `string` | — | 这一项的值，放在 `Tabs` 里时必填 |
| `variant` | `"tab"` `"segment"` | `"tab"` | 选项卡（切换下面整块内容）/ 分段（在底槽里选一个参数值）。放在 `Tabs` 里跟着 `Tabs` |
| `layout` | `"horizontal"` `"vertical"` | `"horizontal"` | 竖排只有分段、32：图标 20 在上，12 号字在下，间距 4，56 × 56，必须传 `icon` |
| `size` | `32` `36` | `32` | 高 32 / 36，左右内边距 12 / 16（`--spacing-12` · `--spacing-16`），字 13 / 14，圆角 8（`--border-radius-8`），图标和文字间距 6。竖排不分尺寸 |
| `icon` | `IconName` | — | 左图标 16，只有选项卡横排有，分段横排没有 |
| `selected` | `boolean` | — | 选中。放在 `Tabs` 里由 `Tabs` 管，单独摆放才传 |
| `disabled` | `boolean` | `false` | 禁用 |

选项卡：默认文字 secondary，悬停文字变 primary，选中底白 10%。分段：项叠在分段的底（白 10%）上，是浅底，用 Light 2：悬停底白 10%（hover），选中底白 6%（常驻底色用默认）。禁用文字白 20%。颜色变化 100ms ease-in-out。没有按下状态。

其余原生 `<button>` 属性都能传，比如 `id`、`aria-controls`。

### Tabs

把一组 `TabItem` 管起来：同一时间只有一个选中，方向键移动选中（← →，分段 ↑ ↓ 也行；跳过禁用项，到头绕回），Home、End 到头尾。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `variant` | `"tab"` `"segment"` | `"tab"` | 里面的 `TabItem` 都跟着它。选项卡是 `role="tablist"`，没有底槽，选项间距 4。分段是 `radiogroup`，带底槽：内边距 4（`--spacing-4`），圆角 12（`--border-radius-12`），底白 10%，选项等宽平分 |
| `layout` | `"horizontal"` `"vertical"` | `"horizontal"` | 同 `TabItem`。不影响方向键：竖排只是每项上图标下文字，整组仍横排 |
| `size` | `32` `36` | `32` | 同 `TabItem`。分段底槽比选项高 8：32 的 40，36 的 44，竖排 64 |
| `value` | `string` | — | 选中的值（受控），和 `onChange` 一起用 |
| `defaultValue` | `string` | — | 默认选中的值（非受控）。没有选中项、或选中的那项禁用了 / 不在了，第一个可用项能 Tab 进来 |
| `onChange` | `(value: string) => void` | — | 选中变化 |

其余原生 `<div>` 属性都能传，比如 `aria-label="分辨率"` 说明这一组是做什么的。
