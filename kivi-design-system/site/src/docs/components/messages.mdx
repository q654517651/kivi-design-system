## 参数

### Toast

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `type` | `"info"` `"success"` `"warning"` `"error"` `"loading"` | `"info"` | 信息 / 成功 / 警告 / 错误 / 加载中。状态图标 16：实心圆 + 镂空符号，圆色 `--color-text-fill-secondary` / `--color-status-success` / `--color-status-warning` / `--color-status-danger`；加载中不画圆，用转圈的 `Loading` 图标，1 秒一圈 |
| `children` | `ReactNode` | — | 提示文字，一行说完，不加标题。14 / 22，primary |
| `action` | `ReactNode` | — | 操作文字，比如「撤销」「取消」。14 / 22，secondary，和文字间距 8。不传就没有 |
| `onAction` | `() => void` | — | 点操作文字 |

高 40，内边距上下 8 左右 16（`--spacing-8` · `--spacing-16`），元素间距 8，圆角 12（`--border-radius-12`），底色 `--color-bg-fill-popup`，不加描边和阴影。

其余原生 `<div>` 属性都能传。`Toast` 只管样子，弹出来用下面的 `Toaster` 和 `toast`。

### Toaster 和 toast

整个应用根上放一个 `<Toaster />`，之后在哪里都能调 `toast`，不用 Provider。`Toaster` 在页面顶部居中，距顶 24，同一时间只有一条，新的顶掉旧的。只放一个，多放几个每个里面都会出现同一条。

| 方法 | 说明 |
|---|---|
| `toast.show({ type, text, action, onAction, duration })` | 弹出一条，返回它的 id。从上方移入，200ms ease-out |
| `toast.update(id, options)` | 换成新的内容，参数同 `show`，没写的回到默认（「取消」换成成功时自然没了）。不重播移入动画；这一条已被顶掉或收起则什么也不做，返回 `false` |
| `toast.hide(id?)` | 收起，淡出 150ms ease-in。不传 `id` 收当前这条；传了但这条已不是它则不动 |
| `toast.info` `success` `warning` `error` `loading` | 简写：`toast.success('文字', { action, onAction, duration })`。`loading` 不自己消失，做完用 `update` 换成成功或错误 |

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `type` | 同 Toast `type` | `"info"` | 类型 |
| `text` | `ReactNode` | — | 提示文字 |
| `action` | `ReactNode` | — | 操作文字，点了先调 `onAction`，再收起这一条 |
| `onAction` | `() => void` | — | 点操作文字 |
| `duration` | `number` | `3000` | 停留毫秒。`0` 是不自己消失；加载中不管填多少都不自己消失。鼠标停在 Toast 上、或键盘聚焦进去时暂停计时，离开后接着走剩下的时间 |

`Toaster` 的 `className`、`ref` 和其余原生 `<div>` 属性落在外层 `.kv-toaster` 上。

### Notification

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `type` | `"info"` `"success"` `"warning"` `"error"` | — | 不传就没有前面的图标。图标和 Toast 一样：16 的实心圆 + 镂空符号，和第一行对齐（上面空 3） |
| `title` | `ReactNode` | — | 标题，14 / 22，primary，最多两行，超出省略 |
| `description` | `ReactNode` | — | 说明，14 / 22，secondary，能换行，最高 6 行（132），再多在里面滚 |
| `onClose` | `() => void` | — | 传了才显示右上角关闭（`CloseSmall`，IconButton 28） |

宽跟着外面，最宽 400；内边距上下 12、左 16、右 12（`--spacing-12` · `--spacing-16`），元素间距 8，标题和说明间距 4，圆角 12（`--border-radius-12`），底色 `--color-bg-fill-popup`，不加描边和阴影。文字多少不定，所以高度不固定，最高 = 标题 2 行 + 说明 6 行 + 内外边距 = 204。

和 Toast 的区别：Toast 一行、3 秒自己消失、顶部居中只留一条；通知有标题和说明、不自己消失、在右上角能留很多条，等用户看完自己关。其余原生 `<div>` 属性都能传，`Notification` 只管卡片的样子，弹出来用下面的 `Notifier` 和 `notify`。

### Notifier 和 notify

整个应用根上放一个 `<Notifier />`，之后在哪里都能调 `notify`，不用 Provider。`Notifier` 在页面右上角，距顶、距右 24，宽 400，**条数不限**，新的放最上面。

- 平时收起成一叠：最前面一张完整，后面的从下边探出 8，最多探出 2 张，每张再小 5%，里面的字不显示。
- 鼠标停上去（或键盘聚焦进去）展开成一列，卡片间距 8；挪开又收起。展开后总高超出窗口时，整列在里面滚。
- 排位、变高都是 300ms ease-in-out；新来的 200ms ease-out 从右边移入；关掉 150ms ease-in 淡出，后面的补上来。
- 鼠标停在通知上时，自动消失的计时暂停。

| 方法 | 说明 |
|---|---|
| `notify.show({ type, title, description, duration })` | 弹出一条，返回它的 id |
| `notify.hide(id)` | 关掉这一条 |
| `notify.clear()` | 全关 |
| `notify.info` `success` `warning` `error` | 简写：`notify.error('生成失败', { description, duration })` |

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `type` | 同 Notification `type` | — | 类型，不传没有图标 |
| `title` | `ReactNode` | — | 标题 |
| `description` | `ReactNode` | — | 说明 |
| `duration` | `number` | `0` | 停留毫秒。`0` 是不自己消失，等用户关 |

`Notifier` 的 `className`、`ref` 和其余原生 `<div>` 属性落在外层 `.kv-notifier` 上。

### Banner

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `type` | `"info"` `"success"` `"warning"` `"error"` | `"info"` | 信息 / 成功 / 警告 / 错误。底是状态色 12%（`--color-status-success-subtle` 等），信息用 `--color-bg-fill-container-light-1`；图标 16，同 Toast（实心圆 + 镂空符号），镂空是透明的 |
| `children` | `ReactNode` | — | 文字，14 / 22，primary，能换多行 |
| `onClose` | `() => void` | — | 传了才显示右边的关闭（`CloseSmall`，IconButton 28）。不传就一直在 |

宽跟着外面，内边距上下 8、左右 12（`--spacing-8` · `--spacing-12`），元素间距 8，圆角 8（`--border-radius-8`），不加描边和阴影。

横幅嵌在面板、弹窗里，常驻不消失，比如视频封装里「请上传符合规格的图片」。浮在屏幕角上的用 Notification，一行说完的用 Toast。其余原生 `<div>` 属性都能传。
