## 规格

[Hugeicons](https://hugeicons.com/icons) 免费版（圆角描边，MIT）：画在 24 的框里，图形缩到 21，线宽 1.6，整体缩放。是描边不是轮廓，颜色跟文字走。模型厂 Logo、KIVI 自家 Logo、猕猴桃不缩，照原样。

| 尺寸 | 线宽 | 用在哪 |
|---|---|---|
| 16（默认） | 1.07 | 按钮、菜单、输入框 |
| 20 | 1.33 | 工具栏、面板标题、弹窗关闭 |
| 24 | 1.6 | 大入口、竖向工具栏 |
| 40 / 64 | 2.67 / 4.27 | 空状态、插图位 |

<details>
<summary>设计怎么用</summary>

- Figma 里放 Icon 组件，在属性面板里选尺寸和图标。
- 改颜色就改 shape 图层的填充，绑文字颜色变量。
- 要底色或点击区域，用按钮包起来，不做进图标里。

</details>

<details>
<summary>研发怎么用</summary>

```tsx
import { Icon } from '@kivi';

<Icon name="Close" />
<Icon name="Search" size={20} />
<Icon name="Loading" spin />
```

- `name` 用图标表里的名字，区分大小写，写错 tsc 会报错。
- `size`：16 / 20 / 24 / 40 / 64，放进按钮这类组件里时不用传。
- `spin` 只给 Loading 用。
- 图标字体在 Iconfont 项目 KIVI_V2，网站也用它：`<span className="iconfont-v2 icon-kivi-v2-Close" />`，名字相同。CSS 地址在 `kivi/iconfont.ts`。Logo 是彩色的，不在字体里，用 SVG。

</details>

<details>
<summary>找不到图标怎么办</summary>

| 阶段 | 怎么做 |
|---|---|
| 原型 | 从 [Hugeicons](https://hugeicons.com/icons) 免费版（Stroke Rounded）下载直接用 |
| 开发 | 先找设计师，加进组件库再用 |
| 设计 | 按下面的步骤加进 Figma |

1. 在 [Hugeicons](https://hugeicons.com/icons) 免费版找（npm 包 `@hugeicons/core-free-icons` 是同一批；`@hugeicons/static` 协议不许改图形，不能用），下载 24 的 SVG。同族有 -01、-02 几个变体的，挑框少、装饰少、意思最直白的。
2. 等比缩到 21，居中放进 24 的框，线宽改成 1.6。
3. 描边版放「_源文件 · 图标描边」页；转轮廓、合并后做成组件，放进「图标」页对应分组，加进 Icon 组件的首选值。
4. 组件描述写「状态：待确认（用在哪）」，设计师确认后转正式。
5. 在 `icons.demos.tsx` 的 `ICON_INFO` 里补名字和意思，重新导出 `kivi/icons.ts`（默认用的 V3 数据在 `kivi/icons-v3.ts`，`icons.ts` 是 V2 数据和新补的图标）。
6. 从「图标」页导出 24×24 单色 SVG，传到 Iconfont 项目 KIVI_V2、重新生成代码，把新的 CSS 地址和图标名写进 `kivi/iconfont.ts`。

Hugeicons 里也没有的，由设计师照 Hugeicons 的画法自己画：线端圆头、转折圆角、只描边；方的 19、横竖长边 20、圆的 20；分开的部分之间至少留 2。小四角星只加给同一件事有普通版和 AI 版、要并排区分的图标（像 SmartEditing）；节点类型图标（文字、图片、视频、音频）不加。

</details>

<details>
<summary>模型厂 Logo</summary>

图标表「模型 Logo」里的厂商 Logo（Openai、Gemini、Kling 这些）都是从 [LobeHub Icons](https://lobehub.com/icons)（MIT）下的厂商原始 Logo。补新的也只从这里找，不从网上别处找，不用 Hugeicons、Lucide 这类图标库里仿的，也不自己画。

1. 在 [LobeHub Icons](https://lobehub.com/icons) 搜厂商或模型名，下载 Mono（单色）版 SVG。不用 Color、Text 版：图标字体只能单色。也可以直接拿 npm 包 `@lobehub/icons-static-svg` 里的 `icons/名字.svg`，同一批。
2. 不改图形、不加描边，等比缩放后居中放进 24 的框。大小按看起来和圆形图标（Localization、Explore）一样大来定：外轮廓大约是直径 19 的圆；特别实的（像 Sora）再小一点；最长边不超过 20。颜色跟文字走，不用品牌色。
3. 做成组件，放进 Figma「图标」页「模型 Logo」组，名字用厂商英文名、首字母大写（和 Kling、Minimax 一样）。组件描述写「状态：待确认（LobeHub：名字）」。
4. 在 `icons.demos.tsx` 的 `ICON_INFO` 里补名字和意思，重新导出 `kivi/icons.ts`（默认用的 V3 数据在 `kivi/icons-v3.ts`，`icons.ts` 是 V2 数据和新补的图标）。

</details>
