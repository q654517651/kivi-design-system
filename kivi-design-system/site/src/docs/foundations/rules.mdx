## 变量

- 颜色、间距、圆角、字号、行高、透明度、时长都用 `tokens.css` 里的语义变量，不写死，不用原始色（`white/8`、`gray/900` 这类）。只有深色一套主题。画布连线例外。
- 变量只有两层（11-05 定）：底下是填充色阶 `fill-1~4`，上面是语义变量（Container 引用色阶，文字、描边、遮罩这些直接写值）。没有原始色这一层：只有深色一套、不换品牌色，用不上；Figma 里隐藏的原始色集合下次同步时删掉。以后要做亮色模式，再在最底下加回原始色。
- Figma 名换 CSS 名：`/` 换成 `-`，前面加 `--`；小数写成横杠（`border/width/1-5` → `--border-width-1-5`）。
- 数值变量用数字命名，不用 xs、sm、xxl；只有 `border/radius/round` 和字重（`regular` / `medium` / `semibold`）例外。
- 间距、圆角、控件高度只用变量和组件已有的档位，不发明新值。
- 组件外面不再叠透明度：要淡就用组件自己的类型（比如「轻」），不在外面套 opacity。

## 颜色和底色

- 看得出的标准：相邻两层（底和填充、默认和悬停、悬停和选中）的对比度不低于 **1.12**（WCAG 对比度算法，我们自己的线，不要求到无障碍的 3:1）。
- 深底、浅底按背景的**亮度**分，不看色值：先把背景叠了的几层合成，算相对亮度（WCAG 算法），**低于 0.015 是深底，0.015 及以上是浅底**。0.015 是固定的分界，不随变量的值变。
- **填充色阶**（11-05）：白色叠透明度，一条四档，越往上越亮。相邻两档的对比度都在 1.12–1.15，升一档就看得出。Container 都引用它，值是一样的。

| 档 | 变量 | 值 | 被谁引用 |
|---|---|---|---|
| 1 | `--color-fill-1` | 白 6% | Light 2 默认 |
| 2 | `--color-fill-2` | 白 10% | Light 1 默认、Light 2 悬停 |
| 3 | `--color-fill-3` | 白 14% | Light 1 悬停、Light 2 按下 |
| 4 | `--color-fill-4` | 白 18% | Light 1 按下 |

- **档位只看背景，不看是什么组件**：同一种背景上，按钮、输入框、标签、卡片、选中项的默认都是同一档。查下表，表里没有的背景按上一条的亮度分界算，算完补进表。

| 背景 | 深浅 | 用哪组 | 默认 / 悬停 / 按下 | 默认和背景的对比度 |
|---|---|---|---|---|
| base | 深 | Light 1 | 10% / 14% / 18%（2 / 3 / 4 档） | 1.29 |
| 玻璃（压在 base 上） | 深 | Light 1 | 同上 | 1.31 |
| surface | 深 | Light 1 | 同上 | 1.34 |
| popup | 浅 | Light 2 | 6% / 10% / 14%（1 / 2 / 3 档） | 1.20 |
| 已经铺了一层 Light 1 的（卡片里、参考格里、菜单行里） | 浅 | Light 2 | 同上 | 1.20 |

- 深底上不用 Light 2。容器自己铺了 Light 1，就给里面的组件传 `--kv-nested-fill`（和 `-hover`、`-pressed`）= Light 2，组件写 `var(--kv-nested-fill, Light 1)`，放进去自动换组，不在组件里写死。
- 每种状态用这一档对应的颜色：
  - 有常驻底色的（平时就有底，包括开关轨道、文字头像这类控件的部件；选中、展开、当前页、播放中这类一直留着的状态）用这一档的默认：深底 Light 1（10%），浅底 Light 2（6%）。
  - 悬停用这一档的 hover，按下用 pressed，不管平时有没有底：深底 14% / 18%，浅底 10% / 14%。平时没底色的东西（菜单项、日历格、无底下拉、文字按钮、列表行）悬停也是 hover，不用默认色。
- 变量按语义用，不准为了亮度跨语义借用：Container 只有 Light 1、Light 2 两档，每档的默认、hover、pressed 各管各的状态。不拿 hover 当默认、不拿 pressed 当选中，也不为了看清在背景上再叠一层颜色。看不清就换档（Light 1 / Light 2）或改背景变量，不借别的状态的变量。
- **什么时候能直接用 `fill-n`**：只有 Container 语义不符（没有状态、不装内容的静态色块），又找不到合适变量时。能点的、有状态的、装内容的一律用 Container。现在允许的只有这几处，要加新地方先改这张名单，检查脚本会拦名单以外的：
  - 叠放露出来的后层（MediaGroup、多图节点 NodeStack）：起点 + 2 档，深底上是 `fill-4`。
  - 小地图里代表节点的色块：起点档，玻璃上是 `fill-2`。
  - 骨架屏的扫光：比骨架底高一档，`fill-3`。
- 对比度 1.12 只管填充要看出层次。禁用态、遮罩的填充不受这条限制：禁用的底和平时一样，只把文字变成 disabled、去掉悬停；遮罩（container-dark、mask）盖在画面上，不要求和 base 拉开。文字、图标的可读性不在这条豁免里。
- **看不清时怎么提**：先确认背景归类对不对（深底、浅底）；归类没错还看不清，说明这一层不该是填充，换背景变量或换组件。不在填充上再叠透明度、不另写颜色、不跳档。只有上面名单里的静态色块按名单写的档数往上提。
- 凹下去的用 container-dark；盖在画布上、必须不透明的用 surface。叠加最多两层。
- 品牌色省着用，不大面积铺底。常见的用处：主操作、勾选、开关打开、进度、拖入提示的图标和字。主要按钮（品牌渐变）一屏只放一个。
- IconButton 没有绿色状态：选中是常驻底色，深底上用 Light 1 默认，图标白。只有收藏例外：收藏了是实心星，图标品牌绿（`data-collected`），底照选中。
- 入口别灰：工具条、侧栏里没选值的入口和有值的一样亮，不用灰字当占位。

## 文字

- 行高只给多行文字：段落、对话、AI 回复、提示词、说明、多行输入、Toast、长文提示，以及按行数截断、折叠的。用变量页「文字样式」表里的搭配。
- 单行文字不设行高：Figma 里用「自动」，代码里不写，跟组件库的默认 1.4（等于苹方的自动行高）。单行的高度由外框定。
- 字号、行高只用变量里的值。Agent 回复用的 Markdown 渲染除外：照线上用的 Ant Design X Markdown 暗色主题，标题 18 / 30 这类照它。

## 布局

- KIVI 是工作站网站，按全屏使用来排版：卡片、格子的列表不写死几列，定一个最小宽度，一排能放几个放几个，屏越宽放得越多（照即梦）。

## 浮层

- 悬浮在页面上的（菜单、下拉、右键、节点工具栏、参数面板、主站输入框）用玻璃：`--color-bg-fill-glass` + `--effect-glass-blur` + 1px `--color-border-subtle`。下面是什么都行。
- 贴在图片、视频上的控件（卡片上的按钮和按钮条、标签、播放器控件）用 on-media：`--color-on-media-fill` + `--effect-glass-blur`，不加描边，只限图片、视频。
- 勾选框 Checkbox 是媒体上的控件，没选时用 on-media 底 + `border-strong` 描边（描边是方框本身，不算外框）；放在别的底上也照用，不另做一套。
- 背景模糊只有两档：32（`--effect-glass-blur`）给玻璃和 on-media；16（`--effect-mask-blur`）给盖在图片、视频上的遮罩（生成中、占位图）。不写别的数；底是不透明的就不加模糊。
- 模态弹窗用 surface，下面一层遮罩。宽度只用 Dialog 的几档。
- Tooltip、Toast 用 popup 实色。
- 浮层都不加投影。
- 浮层离触发元素的距离按出现方式分三档：点开的（菜单、下拉、面板）4；悬停出来的（预览、长文）8；带箭头的 10（箭头 6 + 空 4）。从看得见的边量：挂在面板里的行上（比如技能预览卡）时，从面板外边量。各组件的 `offset` 默认值就是这三档，不另写。
- 悬停预览素材（参考图、附件、标注引用）一律用 `PreviewPopover`，位置、间距、出现时间都一样。

## 按钮

- 按钮一律方的。圆形只在特殊情况下用，只有这几个专用按钮是圆的：SendButton（Agent 发送）、ConnectorRemove（连线删除）、参考区右下角的小圆加号、缩略图上的删除、标注序号气泡（AnnotationMarker，是标注点，悬停、按下只换光标）。IconButton 的 `round` 只给这几个用，别处不许加；要加新的圆形按钮先改这张名单。
- 缩略图上的删除是右上角的小圆：离边 4，18 的圆，黑 40% + 背景模糊，图标 14；出现时那张的序号隐藏。参考区、附件条、Lora 栏共用一份。
- 占位的地方（空状态、引导、待生成）的按钮一律减弱一档：Button「轻」，文字灰。
- 按钮右边的下拉箭头一律减弱一档，和 Select 的箭头一样用 `--color-text-fill-tertiary`。
- Agent 回复下的推荐按钮用 Button「轻」。
- 先分清「做动作」还是「选值」：做动作用 Button / IconButton；几个值选一个用分段（TabItem）；值多或文字长用 Select；开关立刻生效用 Switch；范围调值用 Slider + NumberInput；多选用 Checkbox；切换整块内容用选项卡；只展示用 Tag。

## 提示

- Tooltip 只写工具名，可以带快捷键，不做解释。
- 要解释、要看长文的用 Popover（说明 / 长文）；能操作的内容放 Popover 面板。
- 只有图标的按钮：看图标要猜的配 Tooltip，一眼就懂的通用符号不配（11-05 定）。IconButton 自带提示，内容就是 `label`，默认开；不配的写 `tooltip={false}`。读屏用的 `label` 都要写。
  - 配：画布的缩放条、底部工具栏、节点工具栏；卡片上的操作条（下载、收藏、重新生成…）；选择模型、技能、首尾帧互换、切换对话模型；复制（悬停「复制」，点了变「已复制」）；单个加号（新建画布、新建对话）；侧栏收起 / 展开。
  - 不配：关闭 ×；更多 ⋯；播放器的播放 / 暂停、静音、全屏；左右翻页箭头（日历、追问上一题 / 下一题）；搜索、清除；缩略图右上的删除小圆（悬停已经弹素材预览）。
  - 同一条按钮条里要么都配、要么都不配：反馈条的复制和赞、踩一起配。

## 菜单和选择

- 单选列表（含 Select）的当前项用「选中」底色，不打勾；打勾只给多选，两行的单选例外。
- 能滚的列表最高停在半条上（菜单 7.5 项），最后露半条，一看就知道能滚；不要正好放满整数条。
- 技能没有不能点的状态：不置灰，不出原因浮层。
- 展开箭头指向内容出来的方向（11-05 定）：树形分组（MenuLabel）收起朝右、展开朝下；下拉（Select、ParamPicker、按钮右边的下拉箭头）和就地展开的内容（工具调用、用户消息、日期筛选、多图节点）收起朝下、展开朝上。两类各管各的，不互相统一。
- 列表项里放了东西（「⋯」、按钮、缩略图）时，它离这一项的边要相等：贴着边的三边（右、上、下）距离一样，能做到的四边都一样。比如 36 高的行里放 28 的「⋯」，上、下、右都离 4；同一列表里标题行的按钮和它右边对齐。

## 状态

- 可交互的至少画全默认、悬停、按下、禁用；需要时加选中、加载中、错误。
- 聚焦不加描边：组件没有聚焦框，输入框聚焦也不加，浏览器默认的聚焦框也去掉（前端已关）。键盘聚焦用和悬停一样的样子。
- 生成中不画进度条，进度交给生成中点阵动效。同一页的点阵共用一个方案、一个时钟，节奏一致。
- 生成失败统一写「生成失败，消耗猕猴桃已退回」。
- 不可恢复的删除要二次确认：弹 Dialog，确认钮用 danger，文字写动作名（「删除」）。删除成功、失败都给 Toast：「删除成功」「删除失败，请稍后再试」。
- 生成按钮条件不满足（没写提示词、上传中等）就禁用、置灰，不弹原因提示。余额不足、模型下架这类业务校验不归组件库管，由产品自己处理（11-05 定）。
- 选中的卡片（节点、Lora 卡）外面盖一圈 2px 白 40% 描边，不用品牌色（11-05 定）。

## 动效

- 一律加减速，不用匀速和 CSS 默认 `ease`；只有循环动画（转圈、扫光、流光）用匀速。
- 先按怎么动选缓动（屏幕内移动 ease-in-out，出现 ease-out，消失 ease-in），再按动多远选时长。曲线只从变量里选，不另写 cubic-bezier。
- 跟着一起动的东西和主体用同一个时长。
- 玻璃面板（菜单、下拉、参数面板、Popover panel）出现、消失用同一套：淡入 + 从锚点那边 96% 放大、移 4，出现 200ms ease-out，消失 150ms ease-in。实色的 Tooltip、Popover 提示 / 长文只淡入淡出（11-05 定）。
- 成组展开 400ms 起，每多一张 +10ms，最多 700ms。
- 系统开了「减少动态效果」，生成中用静态扫光。

## 图标

- 图标用 V3：[Hugeicons](https://hugeicons.com/icons) 免费版（圆角描边）缩到 21、线宽 1.6，名字用「图标」页图标表里的名字。缺的从 Hugeicons 补，不用 Lucide 或别的图标库，补法见「图标」页。
- 图标缩放时线宽跟着等比缩：24 → 1.6，20 → 1.33，16 → 1.07（见「图标」页线宽表）。严禁只缩图形不缩线宽，比如 16 的图标线还是 1.6 粗。Figma 里的图标一律转轮廓再用，放进 16、20 的位置线宽才会跟着缩。
- 模型厂 Logo 只用 LobeHub 的原始 Logo（Mono 版），不用图标库仿的，不自己画。

## 组件

- 业务页面用现有组件拼，不为某个页面再造按钮、菜单。
- 不搞特例：缺样子就给通用组件加类型、状态，不在业务组件里单写。
- 同一个东西有一个组件就只用它：结果叠放只用 MediaGroup，悬停预览只用 PreviewPopover，展开收起只用 Collapse。
- 主站 Agent 和画布 Agent 是同一套对话组件，只有产出不同。
- 组件属性命名：样子叫 `variant`，是什么内容（图片 / 视频、成功 / 错误）叫 `type`，生命周期叫 `status`；尺寸写数字（像素）；生成中统一叫 `generating`。
- 改名都进「旧名对照」。
