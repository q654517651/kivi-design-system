# 画布 · 节点

无限画布上的节点本体、节点外框、连接点和连线。对应 Figma「画布」页。状态：待确认 0.1.0。

画布组件是从旧组件库原样迁过来的，所以有几处和通用规则不一样，比如文字 14、节点底 #181818。改已有画布界面时，保持和现有画布一致。

## 节点

一共七种节点：文字、图片、视频、音频、素材上传、视频封装、视频剪辑。

Figma 里用两个组件拼出所有节点：
- **NodeCard 节点卡片**：
  - 状态：引导、待生成、生成中、完成、失败。
  - 可以开关：按钮、底图、倒计时、上传中、文字按钮、图标按钮。
  - 失败时显示失败文案。
- **NodeMedia 节点内容**：
  - 类型：图片、视频、音频、文字。
  - 可以开关：时长、播放条；带时间和正文文字。
- 音频节点里的播放条 PlayBar、声波 AudioWave 是单独的组件。

每种节点每个状态的样子，在「模板 · 画布」页的「节点」分区。

- 默认 256×256，音频节点 341×256。
- 圆角 16。
- 底色 #181818，1px 描边 `--color-border`（白 12%）。
- **引导态**：中间是几个可选的起步方式（比如「自己编写内容」「图片反推提示词」），每项 14 号字、白 50%，悬停底色白 8%、圆角 8。
- **待生成**：中间一个 64 的类型图标。
- **失败**：文字白 50%，内边距 24。

## 节点外框 NodeWrapper 和连接点

- 节点上方是节点名：14 号粗、secondary，和节点间距 8。
- 左右两侧各有一个连接点 ConnectorDot，直径 16，底色 #0A0A0A，2px 描边。
  - 默认：描边白 20%。
  - 已连接：描边白 20%，中间一个 6 的白 20% 实心点。
  - 高亮：描边白 50%，中间一个 6 的白 50% 实心点。
- 悬停或选中：节点外面加一圈 2px 白 40% 描边，圆角 16。
- 节点比例：

| 比例 | 尺寸 |
|---|---|
| 1:1 | 256×256 |
| 3:4 | 256×341 |
| 4:3 | 341×256 |
| 16:9 | 455×256 |
| 9:16 | 256×455 |

## 连线 Connector

| 状态 | 颜色 | 粗细 |
|---|---|---|
| 默认 | --g-workflow-line-color-default（#424242） | 1.5 |
| 激活（悬停、点击、选中节点的关联线） | 白 55% | 2 |
| 拖拽中 | 白 35% | 1.5，虚线 6/6 |
| 执行中 | 白 90% | 1.5，加一道流光，2 秒一轮 |
| 出错 | 白 60% | 1.5 |

悬停或选中连线时，连线中点出现删除按钮 ConnectorRemove：
- 24 的圆，底色 light-1（白 8%），1px 描边 border，背景模糊 6。
- 中间是 Cutting 图标，16。
