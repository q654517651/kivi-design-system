# 画布 · 节点顶部工具栏

选中节点时，出现在节点上方的工具栏 NodeToolbar。对应 Figma「画布」页。状态：待确认 0.1.0。

- **容器**：高 44，内边距 6，按钮间距 8，圆角 12。填充 #181818 70%，1px 白 8% 描边，背景模糊 32。
- **工具栏按钮 ToolbarItem**：
  - 高 32，圆角 8，内边距上下 6、左右 12，图标和文字间距 8。
  - 图标 20，颜色 tertiary；文字 14，白色。
  - 内容有三种：图标加文字、纯文字、纯图标（32×32）。
  - 样式有两种：填充、玻璃。
  - 悬停时底色 light-1（白 8%）。
- **按节点类型分四种**：图片、文字、视频、打组。
  - 图片的包括裁剪；视频的包括抠图、剪辑、封装。
  - 工具之间可以用竖线分组。

## 裁剪框 CropHandles

裁剪图片时出现在节点上：描边 2px，颜色 #4AFF70。
