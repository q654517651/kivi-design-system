# KIVI 设计规范技能

面向 KIVI AI 无限画布 Web 端的界面设计技能，供设计、产品和研发使用。

## 内容

- `kivi-design-system/SKILL.md`：技能入口与核心规则。
- `kivi-design-system/references/`：设计变量、图标、通用组件、画布、Agent、页面和原型规范。
- `kivi-design-system/assets/placeholders/`：35 张占位图。

## 使用

将 `kivi-design-system/` 整个目录放入所用 Agent 支持的技能目录，保留内部文件结构。

## 当前状态

规范来源于 Figma「KIVI UI KIT V2」，当前仍在完善中；具体约束与适用范围见技能入口。
