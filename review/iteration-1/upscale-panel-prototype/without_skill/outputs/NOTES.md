# 高清放大面板原型：说明与假设

打开 `index.html` 即可使用（单文件，图片已内嵌）。图标用的是线上 iconfont CDN，**离线时图标不显示**，文字不受影响。

## 样式来源（ai-design-web 仓库，只读参考）
- 面板：`nodes/image/components/image-enhancement-panel`（420 宽、#191b1d、倍数选项样式）
- 按钮：`components/generate-btn`；开关：packager-modal 里的 `VehicleSwitch`
- 顶部工具栏：`nodes/image/components/topbar-content.tsx`；面板弹出动效：`action-panel-inline.tsx` + `keyframes.less`
- 画布点阵、左侧和左下工具栏、节点描边、端口、loading 效果，都按对应组件的数值还原
- 示例图：从仓库 `doc/图片节点/img` 的截图里裁出来

## 我做的假设（需要 PM 确认）
1. **触发方式**：按需求做成「选中任意图片节点 → 节点下方弹出面板」。线上现在是在顶部栏点「高清」后新建一个下游节点，面板出现在新节点下面。原型保留了顶部栏，「高清」按钮可以收起或展开面板。
2. **倍数文案**：按需求写成 `2x / 4x`，线上同类面板用的是「2倍 / 4倍」。
3. **积分**：2x 和 4x 都写成 20。线上实际值从模型配置读取（`4k-upscale`）；4x 是否更贵需要确认。
4. **保留面部细节**：默认关闭。线上接口目前只有 `upscale_ratio` 参数，这个开关需要后端新增字段。
5. **按钮**：线上按钮显示「🥝 + 积分数」，这里按需求改成「开始放大」，积分挪到左侧那行提示里。
6. **去掉了原图缩略图条**：面板就在原图下方，再放缩略图是重复的。
7. **结果**：点击后在右侧新建「图片高清 · 2x」节点并连线，模拟生成 5 秒（4x 是 8 秒），结束后弹出成功提示。耗时只是模拟值。

## 未覆盖
4x 超出尺寸上限的提示（线上文案「当前放大倍率超过上限」）、余额不足、失败态。顶部栏的其他工具和左侧工具栏点击后只弹一条提示，没有实际功能。
