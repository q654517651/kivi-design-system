## Switch

### 用途

只有开和关两个状态，点一下立刻生效，比如「生成音频」。要选两个以上的值，或者要点「确定」才生效的，用分段选择器。

### 结构

一个胶囊底，里面一个白色圆形把手，四周留 2。

- 文字说明不在组件里，放在旁边（模板里）。参数面板里标签在左、开关在右。
- 只有开关、没有文字时，必须写 `aria-label` 说明它控制什么。
- Tab 聚焦，空格或回车切换。

### 属性（Figma 对应）

| 属性 | 选项 | 代码 |
|---|---|---|
| 开关 | 开 / 关 | `checked={true}` / `{false}`；不想自己管状态就用 `defaultChecked`；切换后触发 `onChange(checked)` |
| 状态 | 默认 / 禁用 | 禁用 `disabled` |

开关没有悬停状态。

### 样子

| 部分 | 值 | 变量 |
|---|---|---|
| 尺寸 | 36 × 20 | — |
| 圆角 | 999（胶囊） | `--border-radius-round` |
| 把手 | 圆形 16，四周留 2，白色 | `--color-text-fill-primary` |
| 开 | 品牌绿 | `--color-brand-solid` |
| 关 | 白 16% | `--color-bg-fill-container-light-1-pressed` |
| 禁用 | 整体透明度 30%，开、关都一样 | `--opacity-30` |

- 开、关切换时，底色和把手一起动，150ms ease-in-out，见动效页。

状态矩阵（已删）：行 开 / 关，列 默认 / 禁用。

### 用法

- 两个状态、点了马上生效的设置用开关，比如「生成音频」。
- 要选两个以上的值，或者要点「确定」才生效的，用分段选择器。
- 标签在左、开关在右，整行对齐。

参数面板：标签在左、开关在右（示例已删，代码如下）：

```jsx
<div style={{ display: 'flex', alignItems: 'center', justifyContent: 'space-between', gap: 12, width: 240, color: 'var(--color-text-fill-primary)', fontSize: 13 }}>
  <span>生成音频</span>
  <Switch aria-label="生成音频" defaultChecked />
</div>
```

## Slider

### 用途

在一个范围里调一个数值，比如时长、语速。

### 结构

轨道 + 已选部分 + 把手，三层叠在一起，整体高 16。

- 宽度拉伸，轨道跟着变长；进度用百分比，不用写死像素。
- 把手起点贴着轨道左端，终点贴着右端，不会伸出轨道。
- 要显示具体数值时，右边配一个数字输入框。刻度和数值写在模板里（Figma「模板 · 画布」页「参数面板」）。
- 没有文字，必须写 `aria-label`。
- 能拖，也能点轨道直接跳到那里。Tab 聚焦后，方向键一次一步，Home / End 到头，PageUp / PageDown 一次十步。

### 属性（Figma 对应）

| 属性 | 选项 | 代码 |
|---|---|---|
| 进度 | 0 / 25 / 50 / 75 / 100（Figma 里先摆几个大概；代码里是范围内任意值） | `value={50}`；不想自己管状态就用 `defaultValue`；变化时触发 `onChange(value)` |
| 状态 | 默认 / 悬停 / 禁用 | 悬停由鼠标触发；禁用 `disabled` |
| 范围 | 最小、最大值、步长 | `min`（默认 0）/ `max`（默认 100）/ `step`（默认 1） |

### 样子

| 部分 | 默认 | 悬停 | 变量 |
|---|---|---|---|
| 整体高度 | 16 | 16 | — |
| 轨道 | 高 4，圆角 999，白 16% | 同默认 | `--color-bg-fill-container-light-1-pressed` |
| 已选部分 | 高 4，圆角 999，品牌绿 | 品牌悬停色 | `--color-brand-solid` / `--color-brand-hover` |
| 把手 | 白色圆形，直径 14 | 直径 16 | `--color-text-fill-primary` |
| 禁用 | 整体透明度 30%，把手保持 14（悬停也不变） | | `--opacity-30` |

- 悬停时把手变大 100ms ease-in-out，已选部分换色，同按钮的悬停。
- 拖动时没有单独的样式，保持悬停的样子。

状态矩阵（已删）：行 默认 / 悬停 / 禁用，列 进度 0 / 25 / 50 / 75 / 100。

### 用法

- 时长、语速这类在范围里连续调的数值用滑块。
- 要看到具体数字，右边配数字输入框，两个联动：拖滑块数字变，改数字滑块动。
- 只有几个固定选项的，用分段选择器，不用滑块。

时长：滑块 + 数字输入框（联动）的说明（原文）：范围 1 到 15 秒是示例，实际范围看具体功能。数字输入框见「输入控件」页 NumberInput。（示例仍在网站页面里。）

## Checkbox

### 用途

可以多选的用勾选框。方形用在列表和表单，圆形用在图片多选。

### 结构

16 的方框 + 可选的文字，水平排列，间距 8。整行（方框加文字）都能点。

- 圆形用在图片多选时不带文字，放在图片右上角，距上、右各 8。
- 文字 13 号常规，primary，写在组件的内容里。
- 没有文字时，必须写 `aria-label`。
- 「部分」只用在全选框上，表示下面选了一部分。
- Tab 聚焦，空格切换。

### 属性（Figma 对应）

| 属性 | 选项 | 代码 |
|---|---|---|
| 形状 | 方形 / 圆形 | `shape="square"` / `"round"`，方形是默认 |
| 选中 | 否 / 是 / 部分 | `checked={false}` / `{true}` / `"mixed"`；不想自己管状态就用 `defaultChecked`；点一下触发 `onChange(checked)`，「部分」点完变成 `true` |
| 状态 | 默认 / 悬停 / 禁用 | 悬停由鼠标触发；禁用 `disabled` |
| 显示文字、文字 | 开 / 关 | 有没有内容：`<Checkbox>选项</Checkbox>` |

### 样子

| 选中 | 默认 | 悬停 | 变量 |
|---|---|---|---|
| 否 | 黑 40% 底 + 1px 白 50% 描边 | 描边变白 100% | `--color-on-media-fill` / `--color-border-strong` / `--color-text-fill-primary` |
| 是、部分 | 品牌绿底，没有描边 | 品牌悬停色底 | `--color-brand-solid` / `--color-brand-hover` |

- 方框 16 × 16，方形圆角 4（`--border-radius-xxs`），圆形 999（`--border-radius-round`）。
- 对勾和横线是黑色（`--color-text-fill-on-brand`），线宽 1.5，圆头。「是」画对勾，「部分」画一条横线。
- 没选时用黑 40% 底，是为了放在图片上也看得清。
- **禁用**：整体透明度 30%（`--opacity-30`），方框和文字一起，选中与否都一样。
- 文字和方框的间距 8（`--spacing-sm`），文字 13 号常规，primary。

状态矩阵（已删）：行 方形 / 圆形 × 没选 / 选中 / 部分（共 6 行），列 默认 / 悬停 / 禁用。

### 用法

- 可以选多个的用勾选框：列表、表单、图片多选。
- 只能选一个的不用勾选框：选比例、分辨率用分段选择器，开关类用开关。
- **方形**：列表和表单。**圆形**：图片多选。
- **部分**：只给全选框用。下面一个都没选是「否」，选了一部分是「部分」，全选了是「是」。点「部分」的全选框，变成全选。

示例说明（原文）：
- 列表全选：点「全选」，下面跟着全选或全不选；下面选了一部分，「全选」自动变成「部分」。
- 图片多选：圆形，右上角距边 8。勾选框盖在图片上，不带文字。点勾选框选图片。
（两个示例仍在网站页面里。）
