## 页面开头

操作之后告诉用户「发生了什么」：Toast 轻提示、Loading 加载、Skeleton 骨架屏、EmptyState 空状态，四个组件。

Toast 和 Tooltip 长得像，但用途不同：Tooltip 是鼠标悬停时解释一个东西，Toast 是操作完成后系统主动告诉用户结果。

## Toast 轻提示

在右边面板选类型、开关操作、改文字，和 Figma 右侧属性面板一样。下面的代码跟着变，可以直接复制。这里摆的是 `Toast` 的样子，怎么弹出来见「调用方式」。

### 用途

操作完成后，系统主动告诉用户结果。几秒后自己消失，不打断操作。

### 结构

左图标 + 文字 + 操作文字（可选），水平排列，间距 8。

- 左边是 16 的状态图标：实心圆 + 镂空符号，符号的颜色就是弹层底色。加载中不画圆，直接用 Loading 图标。
- 文字一行说完，不加标题。
- 操作文字在最右边，比如「撤销」「取消」，点了做一个动作。

### 属性（Figma 属性 ↔ 代码）

| 属性 | 选项 | 代码 |
|---|---|---|
| 类型 | 信息 / 成功 / 警告 / 错误 / 加载中 | `type="info"` / `"success"` / `"warning"` / `"error"` / `"loading"`，信息是默认 |
| 文字 | 提示文字 | `children`；用 `toast.show` 时是 `text` |
| 显示操作 | 开 / 关，默认关 | 传不传 `action` |
| 操作文字 | 默认「撤销」 | `action="撤销"`，点了调 `onAction` |
| 状态图标 | 跟着类型走 | 不用写；加载中是 `Icon` 的 `Loading` 转起来 |

### 样子

#### 类型

| 类型 | 圆的颜色 | 符号 |
|---|---|---|
| 信息 | secondary · `--color-text-fill-secondary` | 感叹号「i」 |
| 成功 | status/success · `--color-status-success` | 对勾 |
| 警告 | status/warning · `--color-status-warning` | 感叹号 |
| 错误 | status/danger · `--color-status-danger` | 叉 |
| 加载中 | 不画圆，Loading 图标 primary · `--color-text-fill-primary` | 旋转，1 秒一圈，匀速 |

#### 规格

| 项 | 值 | 变量 |
|---|---|---|
| 高 | 40 | — |
| 内边距 | 上下 8，左右 16 | `--spacing-sm` · `--spacing-lg` |
| 元素间距 | 8 | `--spacing-sm` |
| 圆角 | 12 | `--border-radius-md` |
| 底色 | popup（弹层色，和 Tooltip 一样），不加描边和阴影 | `--color-bg-fill-popup` |
| 文字 | 14 / 22，常规，primary | `--font-size-14` · `--font-line-height-22` · `--color-text-fill-primary` |
| 状态图标 | 16；符号描边 1.6、圆头，颜色同底色 | `--color-bg-fill-popup` |
| 操作文字 | 14 / 22，常规，secondary，和前面的文字多空 8 | `--color-text-fill-secondary` |
| 最大宽度 | 【待定】 | — |
| 操作文字的悬停、按下 | 【待定】 | — |

#### 位置和动效

| 项 | 怎么定 |
|---|---|
| 位置 | 页面顶部居中，距顶 24 |
| 数量 | 同一时间只留 1 条，新的顶掉旧的 |
| 出现 | 从上方移入，200ms · ease-out（`--motion-duration-200` · `--motion-ease-out`） |
| 停留 | 3 秒后自己消失；加载中不消失，结束后换成成功或错误 |
| 消失 | 淡出，150ms · ease-in（`--motion-duration-150` · `--motion-ease-in`） |

见[动效](/foundations/motion)。

### 调用方式

不用 Provider，不用在组件里取方法：整个应用根上放一个 `Toaster`，之后在哪里都能调 `toast`，组件里、请求回调里都行。`Toaster` 渲染在页面顶部居中，距顶 24，同一时间只有一条。

```tsx
// 应用根上放一次
<Toaster />

// 之后在哪里都能调
toast.show({ type: 'success', text: '已保存到我的作品' });
toast.show({ type: 'success', text: '已删除 1 张图片', action: '撤销', onAction: undo });

// 常用的几种有简写
toast.success('已保存到我的作品');   // 也有 info / warning / error / loading

// 加载中不自己消失，做完了换成成功或错误
const id = toast.loading('正在上传 3 张图片', { action: '取消', onAction: cancel });
toast.update(id, { type: 'success', text: '上传完成' });

toast.hide();   // 收起当前这条
```

| 方法 | 做什么 |
|---|---|
| `toast.show({ type, text, action, onAction, duration })` | 弹出一条，返回它的 id。旧的直接被顶掉，新的从上方移入 |
| `toast.update(id, options)` | 把这一条换成新的内容，参数和 `show` 一样，没写的回到默认（所以「取消」换成成功时自然就没了）。还是同一个元素，不重播移入的动画；这一条已经被顶掉或收起了就什么也不做，返回 `false` |
| `toast.hide(id?)` | 收起：淡出 150ms 后拿掉。不传 `id` 收当前这条；传了 `id` 但这条已经不是它了就不动 |
| `toast.info` / `success` / `warning` / `error` / `loading` | 简写：`toast.success('文字', { action, onAction, duration })` |

| 参数 | 选项 | 说明 |
|---|---|---|
| `type` | 信息 / 成功 / 警告 / 错误 / 加载中 | 默认信息 |
| `text` | 提示文字 | 一行说完 |
| `action` | 操作文字 | 点了先调 `onAction`，再收起这一条 |
| `duration` | 毫秒，默认 3000 | 0 是不自己消失；加载中不管填多少都不自己消失 |

- `Toaster` 只在应用根上放一个。多放几个，每个里面都会出现同一条。
- 文档里这个演示把 `Toaster` 框在舞台里，加了 `style={{ position: 'absolute' }}`，项目里不用加。

### 用法

- 操作做完了，告诉用户结果：成功、失败、要注意的事。
- 要等一会儿的操作用「加载中」，不消失；做完了把它换成成功或错误。
- 可以带一个操作，比如「撤销」「取消」「查看原因」。
- 文字一行说完，不加标题。
- 鼠标悬停时解释一个东西，用 Tooltip，不用 Toast。
- 页面里一直挂着的提醒条，不是 Toast；Figma 里暂时不收，用的地方多了再做 Alert。

#### 被删掉的示例（页面里留了「点出来试试」）

- 类型：五种 Toast 并排（信息 / 成功 / 警告 / 错误 / 加载中，文字都是「提示文字」）。
- 三个例子：`成功「任务已提交」`；`加载中「正在上传 3 张图片」+ 操作「取消」`；`错误「生成失败，请重试」+ 操作「查看原因」`。
- 点出来试试：Toast 从上方移入，3 秒后淡出。连点几次，新的会顶掉旧的。「上传」是加载中：不消失，2 秒后换成成功；点「取消」直接收起。

## Loading 加载

### 用途

转圈 + 可选文字，告诉用户正在等。

### 结构

转圈图标 + 文字（可选）。图标就是图标库里的 `Loading`，和按钮「加载中」用的是同一个，1 秒转一圈，匀速。

- 小：横排，图标在左，文字在右。
- 中、大：竖排，图标在上，文字在下。

### 属性（Figma 属性 ↔ 代码）

| 属性 | 选项 | 代码 |
|---|---|---|
| 尺寸 | 小 / 中 / 大 | `size="sm"` / `"md"` / `"lg"`，小是默认 |
| 显示文字 | 开 / 关，默认开 | 有没有 `children` |
| 文字 | 默认「加载中…」 | `children`，比如 `<Loading>加载中…</Loading>` |
| 图标 | Loading，转起来 | 不用写，组件自带 |

### 样子

| 尺寸 | 图标 | 文字 | 排列 |
|---|---|---|---|
| 小 | 16 | 12 / 20，常规，secondary · `--font-size-12` | 横排，间距 8 · `--spacing-sm` |
| 中 | 24 | 13 / 20，常规，secondary · `--font-size-13` | 竖排，间距 8 · `--spacing-sm` |
| 大 | 40 | 14 / 22，常规，secondary · `--font-size-14` | 竖排，间距 12 · `--spacing-md` |

- 图标颜色 primary（`--color-text-fill-primary`），文字颜色 secondary（`--color-text-fill-secondary`）。
- 转圈 1 秒一圈，匀速，见[动效](/foundations/motion)。

### 用法

- **知道内容长什么样**（列表、卡片）：用骨架屏，不用转圈。
- **不知道长什么样、或者很快就好**：才用转圈。
- **按钮里的加载**：用 Button 的「加载中」状态，见[按钮](/components/button)，不用 Loading。
- **小**：一行里的小块加载。**中**：卡片里。**大**：整块区域。

#### 被删掉的示例

- 三个尺寸并排：小 / 中 / 大，文字都是「加载中…」。
- 卡片里：中。放进 240 × 240 的卡片框（圆角 `--border-radius-md`，底 `--color-bg-fill-container-light-2`），文字「图片上传中…」。
- 整块区域：大。放进最宽 560、高 240 的区域框（圆角 `--border-radius-lg`，底 `--color-bg-fill-base`），文字「加载中…」。

（这几个场景框是演示用的 `Frame`，原来在 `feedback.demos.tsx`，已随页面一起删。）

## Skeleton 骨架屏

### 用途

内容还没出来时，先用灰块占住位置，告诉用户内容长什么样、很快就来。

### 结构

一个色块，没有内容。组件只管颜色和圆角，形状照真实内容摆：图片、卡片用矩形，头像用圆形，文字用文字行。

### 属性（Figma 属性 ↔ 代码）

| 属性 | 选项 | 代码 |
|---|---|---|
| 形状 | 矩形 / 圆形 / 文字行 | `shape="rect"` / `"circle"` / `"text"`，矩形是默认 |
| 宽、高 | 照真实内容 | `width={160}` `height={90}`，也可以写 `'60%'`；文字行高默认 12，不用写 |

Figma 里摆的 160×90、32×32、200×12 只是示意，不是默认尺寸。

### 样子

| 形状 | 用在 | 圆角 |
|---|---|---|
| 矩形 | 图片、卡片 | 8 · `--border-radius-sm` |
| 圆形 | 头像 | 999 · `--border-radius-round` |
| 文字行 | 文字 | 高 12，圆角 4 · `--border-radius-xxs` |

- 底色白 8%（`--color-bg-fill-container-light-1`）。
- 动效：高光从左往右扫，白 12%（`--color-bg-fill-container-light-1-hover`），1.4 秒一轮，匀速（linear）。Figma 里看不到动效。
- 高光的渐变形状【待定】：Figma 只写了「白 12%，从左往右」，先用两头透明的横向渐变。
- 系统开了「减少动态效果」时不扫光，只留底色。

### 用法

- 知道内容长什么样（列表、卡片）就用骨架屏；不知道、或者很快就好的才用 Loading。
- 骨架屏的组合是模板，不做成组件：哪个页面要用，照着真实布局拿 Skeleton 摆。模板在 Figma 的「模板 · 通用」页「骨架屏」分区【待确认】。

#### 被删掉的示例（页面里留了「一条带头像的卡片」）

- 三个形状并排：矩形 160 × 90、圆形 32 × 32、文字行 200。

## EmptyState 空状态

### 用途

页面、面板、下拉里没有东西可看时，用 IP 插图告诉用户为什么是空的、下一步做什么。

### 结构

IP 插图 + 标题 + 一句说明（可选），竖排居中。

- **插图**：每个场景一张 IP 图，背后有一圈绿色光晕，脚下有一块地面阴影。
- **标题**：一句话说清楚现在是什么情况。
- **说明**（可选）：写清楚下一步做什么。下拉里不要说明。
- **引导操作**（可选）：需要引导操作时，在插图下面再放一个「中」号按钮（次要），间距 24。

IP 图从 Figma 反馈页导出，放在 `assets/empty-state/`：`empty.png`（暂无内容）、`no-favorites.png`（暂无收藏）、`offline.png`（无网络）、`failed.png`（生成失败）。320×320，够大号 160 用两倍图。

### 属性（Figma 属性 ↔ 代码）

| 属性 | 选项 | 代码 |
|---|---|---|
| 场景 | 暂无内容 / 暂无收藏 / 无网络 / 生成失败 | `scene="empty"` / `"favorite"` / `"offline"` / `"failed"`，暂无内容是默认；换的是 IP 图，样式一样 |
| 尺寸 | 大 / 小 | `size="lg"` / `"sm"`，大是默认 |
| 标题 | 标题文字 | `title="还没有作品"` |
| 显示描述 | 开 / 关，默认开 | 传不传 `description` |
| 描述 | 一句话说清楚下一步做什么 | `description="去画布生成第一张图"` |
| 引导操作 | 一个中号次要按钮 | `action={<Button>去画布</Button>}` |

四张图的路径在 `EMPTY_STATE_IMAGES` 里，项目里把图放到自己的静态目录后改这里；个别地方想换图，传 `image="…"`。

### 样子

| 项 | 大（页面、大面板） | 小（下拉、侧栏） |
|---|---|---|
| 插图 | 160 | 96 |
| 插图和文字间距 | 16 · `--spacing-lg` | 8 · `--spacing-sm` |
| 标题 | 16 / 24，粗，primary | 14 / 22，粗，secondary |
| 描述 | 14 / 22，常规，tertiary | 12 / 20，常规，tertiary |
| 标题和描述间距 | 4 · `--spacing-xxs` | 4 · `--spacing-xxs` |

- 文字颜色：primary `--color-text-fill-primary`，secondary `--color-text-fill-secondary`，tertiary `--color-text-fill-tertiary`。
- 光晕：比插图大 10% 的圆，品牌绿 10% 到 0 的径向渐变。地面阴影：宽是插图的 60%，黑 50% 到 0 的径向渐变。小号等比缩小。
- 最大宽度【待定】：Figma 里宽度跟着文字走。
- 旧的线条图标空状态（收藏、图片、视频、人脸）不再用。

### 用法

- **暂无内容**：页面或面板里还没有东西。**暂无收藏**：收藏夹是空的。**无网络**：网络断了。**生成失败**：生成没成功。
- **大**：页面、大面板。**小**：下拉、侧栏。下拉里去掉描述。
- 说明写清楚下一步做什么，比如「去画布生成第一张图」。
- 需要引导操作时，在下面放一个中号次要按钮。

#### 被删掉的示例

- 大、小各一个，文字「标题文字 / 一句话说清楚下一步做什么」（无代码）。
- 4 个场景 × 大、小的矩阵（`EmptyStateMatrix`）。4 个场景各用一张 IP 图。大号放页面和大面板，小号放下拉和侧栏。
- 页面里：大。放进最宽 800、高 420 的页面框，标题「还没有作品」，说明「在左侧写下描述，生成第一张作品」。
- 下拉里：小，不要描述。放进 320 × 240 的玻璃下拉框（`--color-bg-fill-glass` + `--effect-glass-blur` + 描边 border-subtle），标题「没有找到相关模型」。
- 带引导操作：下面放中号次要按钮。标题「还没有作品」，说明「去画布生成第一张图」，按钮「去画布」。（页面里的属性面板新加了「显示引导操作」开关来覆盖。）
