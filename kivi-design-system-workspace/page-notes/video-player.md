# 视频播放器：前端现状（10-29 盘点，ai-design-web main 分支，只读）

用户 10-29 提：节点、主站生成结果、全屏预览三处播放器不统一，问怎么整。还没拍板。

## 现状

- 共享播放器 `packages/shared/src/components/CustomVideoPlayer`（react-player + media-chrome），约 17 处在用，靠 `controlMode` 切出 4 套控制条：
  - `millisecond-control`：主站生成卡片悬停。左下播放 + `1.2 / 5.0s`，2px 进度贴底边。
  - `main-preview-control`：画布节点、详情弹窗、工具结果。播放 + `00:03 / 00:15`，右边音量图标 + 音量条（节点 50px、弹窗 80px），下一行 2px 进度。
  - `only-duration`：不悬停时左下 `00:15` 徽标。
  - 不传模式就是浏览器原生 controls（换脸结果页）。
- 进度条：2px 白 50% 轨道，悬停变 4px、出 8px 圆点。
- 默认音量 0；悬停 600ms 静音播放，移出暂停（有的回到 0，有的不回）。
- 没用共享组件的：画布历史面板、Agent 聊天附件、视频剪辑器（时间码到帧）、包装弹窗选帧和裁剪、多模态编辑外置控制条（14px 绿把手滑条，没时间）、音频卡片。
- 时间格式至少 7 种：`1.2 / 5.0s`、`00:03 / 00:15`、`0:01 / 0:15`、`00:15`、`5s`、`00:03:12`（帧）、带小时的。
- 画面上的操作按钮两套：主站（白底 .4、模糊 4、有边框）和画布（.45、模糊 12、无边框），都是 32 圆角 8；收藏一个在右上一个在左上。
- 全屏、倍速、清晰度「原画」、截图：代码里都没有。用户截图里节点的「胶囊 + 圆形静音/全屏」、预览的「原画」在 main 分支搜不到，可能是别的分支或线上新版。
