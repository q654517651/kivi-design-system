## GenPrompt

在右边面板选长度、开关，和 Figma 右侧属性面板一样。鼠标移到参考区上，下面会弹出浮层显示全部参考素材。

### 用途

主站生成记录的头：一条记录最上面那块，提示词 + 参数。工具类任务（抠图、高清…）没有提示词，只显示一排参数。

### 结构

垂直排列，间距 4：提示词 + 参数（一排 Tag，间距 6，放不下换行）。不显示时间。

- **提示词**：生成任务一定有，没有提示词不让提交；复制按钮固定跟在后面，不能关。工具类任务没有提示词，这一行整个不显示。短的在一行内，复制按钮紧跟在文字后。超出两行的最多 2 行，末尾省略；复制按钮放在第二行行尾，左边 40 的渐变从透明过渡到底色，盖住被截断的文字。
- **参数**：任务类型（Tag 带左图标：图片生成 / 视频生成 / 音频生成；工具类直接写工具名，比如抠图、扩图、视频拼接）· 参考区 · Tag 1–3（Lora 带缩略图、清晰度、比例、时长、语速、音调…）· 模型（左图标 + 模型 Logo）。
- **参考区**：所有参考素材放一块，图片、视频（首帧）、音频可以混排，原图、原视频也放这里。图在前，后面跟参考方式文字（首帧 / 首尾帧 / 全能参考 / 参考图 / 原图…）。代码里单独成 `GenPromptRefs`，放在 GenPrompt 的参数里。
- 帧率、张数、生成音频都不展示；没有图生图、控制图、ControlNet。

<Tag kind="draft">待确认</Tag> 参数的顺序。Figma 的说明文字写「任务类型 · 参考区 · Tag 1–3 · 模型」，但组件和「模板 · 主站」里实际画的是「任务类型 · 模型 · 参考区 · Tag 1–3」。下面的示例按画出来的排。

组件里摆的是最全的情况（生视频），用的时候把不要的 Tag 隐藏、改文字，不另做变体。各种情况的摆法见「模板 · 主站」的「参数全集」。

| 提示词 | 文字。生成任务一定有；工具类任务没有 | `prompt="…"`；工具类任务不传，只显示参数 |

## ResultTile

在右边面板选类型和状态。鼠标移到完成的格子上也会出操作。

### 用途

主站生成结果的一格：一条记录里的一张图或一段视频。每格的任务独立：各自生成、完成或失败。画布 Agent 不用它，用 NodeCard。

### 结构

一个方块，里面叠放：画面 + 左上任务角标（生成中）+ 右上操作 + 左下快捷操作（悬停才出）。视频完成时左下是时长，悬停时底部出播放条。

- 快捷操作的最后一个是「更多」。
- 任务角标 = Tag 覆盖，只有文字。
- 生成中时格子里放 `GeneratingDots`，铺满格子。
- 没有排队状态。

### 属性

| 属性 | 选项 | 代码 |
|---|---|---|
| 类型 | 图片 / 视频 | `type="image"` / `"video"`，图片是默认 |
| 状态 | 生成中 / 完成 / 悬停 / 失败 | `status="loading"` / `"done"` / `"failed"`，完成是默认；悬停由鼠标触发 |
| 画面 | 图片、视频首帧 | `src="./placeholders/kiwi-glass-1x1.webp"` |
| 画面完整显示 | 比例和格子不一致时用，默认铺满 | `fit` |
| 任务角标 | 文字，生成中用 | `badge="59s 生成中"` |
| 视频时长 | 文字，完成的视频用 | `duration="00:05"` |
| 右上操作 | 删除、下载、收藏 | `topActions={[{ icon: 'Delete', label: '删除', onClick }]}` |
| 左下快捷操作 | 最后一个是「更多」 | `quickActions={[…]}`，写法同上 |
| 播放条 | 视频悬停时出 | `playBar={<PlayBar />}` |
| 失败文字 | 默认「生成失败，消耗猕猴桃已退回」 | `failedText` |

### 样子

| 部分 | 规格 |
|---|---|
| 整体 | 默认 256 方，宽高随排版改；底 surface，描边 border-subtle 1，圆角 6 · `--border-radius-xs`，内容裁切 |
| 画面 | 默认铺满；比例不一致时用 `fit` 完整显示，留底色 |
| 任务角标 | Tag 覆盖，左上，离边 8 |
| 右上操作 | 删除、下载、收藏，IconButton 28 · 浮层，间距 4，离边 8 |
| 左下快捷操作 | IconButton 28 · 浮层（上下统一 28），间距 4，离边 8；视频要抬到播放条上面（38 + 8） |
| 视频时长 | Tag 覆盖，左下，离边 8 |
| 播放条 | PlayBar，宽跟格子，高 38，贴底 |

| 状态 | 样子 |
|---|---|
| 生成中 | 生成中动效铺满格子，同 NodeCard；左上任务角标 |
| 完成 | 画面；视频左下有时长 |
| 悬停 | 右上出删除 / 下载 / 收藏；左下出快捷操作；视频底部是播放条 |
| 失败 | EmptyState 小 · 生成失败，居中，写「生成失败，消耗猕猴桃已退回」 |

- 任务角标写「59s 生成中」。剩余时间由前端按最近 1 小时同类任务耗时估算，算不出时只写「生成中」。Figma 里画的角标只有「59s」。<Tag kind="draft">待确认</Tag>
- 悬停时操作出现 150ms ease-out，消失 150ms ease-in，见[动效](/foundations/motion)。
- 生成中动效见[动效](/foundations/motion)。

矩阵里缩成 184 宽方便并排，规格是 256。

### 用法

- 一条记录的结果网格里，每一格一个 ResultTile。每格各自生成，所以一条记录里可以同时有生成中、完成、失败的格子。
- **快捷操作**按代码现有的排：图片常显「图片编辑、图生视频、一键垫图」，高清修复、一键抠图、一键扩图、添加文件夹收进「更多」；视频常显「视频编辑、视频高清、视频循环」，视频拼接收进「更多」。<Tag kind="draft">待定</Tag> 哪些常显。
- **失败**时消耗的猕猴桃已退回，所以文字里直接写。
