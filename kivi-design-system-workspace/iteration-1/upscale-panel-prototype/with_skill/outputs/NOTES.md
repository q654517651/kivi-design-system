# 高清放大面板原型：说明

双击 `index.html` 打开即可（需要联网加载 Lucide 图标）。

## 怎么点
- 打开时「图片 1」已选中：上方是节点工具栏，下方是「高清放大」面板。
- 点空白处或按 Esc 取消选中，再点节点重新弹出。工具栏里的「高清」可以收起或展开面板。
- 2x / 4x 切换后，标签右侧的「输出 W × H」会跟着变。
- 点「开始放大」：按钮先转圈，右侧新建一个「高清放大 2x/4x」节点并连线（连线流光，节点显示生成中），3 秒后完成并弹出成功 Toast。新节点也能选中，再放大一次。
- 画布可以拖动空白处平移，⌘ + 滚轮缩放，左下角也能缩放。其他入口点了只弹提示，没有接入。

## 需要产品确认的假设
1. **结果放哪**：做成在右侧新建节点并连线，原图保留不覆盖。
2. **积分**：按需求固定写「预计消耗 20 积分」，没有随 2x / 4x 变化。如果 4x 价格不同，告诉我数值。
3. **「保留面部细节」默认关**。
4. **输出尺寸提示**（「输出 2048 × 2048」）是我加的，方便看出倍数的区别；不需要可以去掉。也没有设分辨率上限（4096 的图再放 4x 会显示 16384）。
5. **节点工具栏的条目**（裁剪、扩图、高清、抠图、下载）只是示意，以现有画布为准。

## 和规范的对应 / 临时做法
- 面板按「参数面板模板」拼：玻璃浮层（glass + 1px 描边 + 模糊 16 + 圆角 12），内边距 16，行间距 16；分段选择器、开关、主要按钮（中 32）都是规范组件。
- **规范里没有这个面板**：宽 320 是临时取值（NodePanel 的 620–800 是给提示词面板的，这里内容少）；面板标题行（图标 20 + 16 号标题）也是临时补的。
- **画布旧样式（占位）**：节点底 #181818、圆角 16、选中外圈白 40%、工具栏文字 14、连接点底 #0A0A0A，照现有画布做，以后统一。节点选中没用 `border-focus` 品牌绿，是为了和线上画布一致。
- Toast 成功图标用的 status/success 是占位值。
- 图片用占位块代替（规范：用户作品用占位块）。
- 缺图标：积分（面板里只写文字，没放图标）；画布左侧工具栏的「历史」缺 History 图标，先省略。
