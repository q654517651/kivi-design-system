# 页面骨架

KIVI 现有页面怎么摆。尺寸是 2026-10 从代码里量的；颜色、圆角、字号按 v2 规范写，和代码现状不一样的地方在括号里注明「代码现在是…」。新页面照这里的结构摆，视觉一律用 v2。

## 基本前提

- 只有桌面端 Web。默认布局最小宽度 1440，没有手机版。
- 唯一常用的断点是 ≥1920：网格多加几列，左栏变宽。
- 两种外壳：
  - **默认布局**：有顶栏。发现、AI 创作、AI 工具箱、增长工具、我的资产、画布列表都用它。
  - **画布布局**：没有顶栏，画布铺满整屏。

## 默认布局

### 顶栏
- 高 72，左右内边距 24，吸顶，底色 base，下边 1px border-subtle。
- 从左到右：Logo（64×26，右边留 24）→ 导航 → 右侧操作区。
- **导航项**：按选项卡（大）做，高 36、圆角 8、14 号。未选中 secondary；选中和悬停用白 8% 底 + 白字。项间距 16。（代码现在是 40 高、圆角 12。）
- **右侧操作区**，项间距 24：
  - 教程、反馈、语言：纯图标按钮，文字型。
  - 余额胶囊：高 36，圆角 999，底色 light-1。
  - 头像：32。（代码现在是 36。）

### 内容区
- 外壳不加内边距，每个页面自己管：页面左右边距 24。
- 内容区高度一般是 `calc(100vh - 72px)`，底色 base。

## 画布布局

画布铺满整屏，其他东西浮在画布上，离屏幕边 24。

- **画布底**：base 底色上铺一层点阵。点是白色、透明度 18%、大小 1，每 18px 一个（代码里是 `dotSize: 1`、`dotOpacity: 0.18`、`CANVAS_GRID_SIZE`）。画布上不要再加别的纹理或渐变。

| 位置 | 是什么 | 尺寸和样式 |
|---|---|---|
| 左上（left 24, top 14） | 首页图标 + 分隔线 + 画布名 | 内边距 8 12 8 8，间距 8，圆角 12，图标 20，分隔线 1×16 |
| 右上（right 24, top 14） | 教程、语言等 | 高 44，内边距 4 8，圆角 12，项间距 16，图标 20 |
| 左侧，垂直居中（left 24） | 画布工具栏 CanvasToolbar | 宽 56，胶囊形，图标 24，见「画布」 |
| 左下（left 24, bottom 24） | 缩放条 | 高 36，内边距 0 6，间距 4，圆角 8，按钮 28 · 图标 20 |
| 右侧 | 对话面板 | 默认宽 500，可拖到 360–720；挤占画布宽度，不是浮层；可以收起 |

- 画布上常驻的浮条要盖住画布内容，所以用不透明的 surface，加 1px border-subtle。
- 选中节点后弹出的工具栏、菜单、参数面板用玻璃。
- **对话面板**：
  - 左边 1px border-subtle，内边距 16，元素间距 16，头部高 36。
  - 输入框在底部，按提示词输入框模板做：圆角 24，内边距 16，最小高 178，最高 336。
- 从左侧工具栏弹出的面板（比如工作流模板）贴着工具栏右边出现，中间留 4（代码里是 left 86）。
- 分享预览页：画布铺满，顶部水平居中一条浮条，top 16，宽 `min(1000px, 100vw - 32px)`，内边距 16，圆角 16。

## 页面类型

### 1. 生成工作台：左边表单，右边结果
AI 创作（/home）、AI 工具箱、增长工具都是这种。

- **左栏**：
  - 宽 400–488（增长工具 240，≥1920 时 288），离边 24。
  - 一张卡片：圆角 16，内边距 16，底色 light-2（代码现在是白 8%）。
  - 表单块之间间距 24；每块按表单行模板：标签 13 号 secondary，和控件间距 8。
  - 底部是生成按钮：主要 · 大（36），宽度撑满（代码现在是 44 高）。
- **右栏**：
  - 结果区宽 940–1200，居中，左右内边距 80。
  - 顶部是选项卡，下面是结果列表，间距 16；每组结果之间间距 48。
  - 每组结果：上面是参数标签（Tag · 默认）和提示词（14 号，最多 2 行），下面是图片网格。网格 4 列，单张方图时 3 列，间距 4，图片圆角 8。
- 工具箱有任务队列时，右边多一栏，宽 186。

### 2. 媒体网格：一屏铺满图片或视频

- 页面左右 24。

- **资产网格**：7 列（≥1920 时 8 列），间距 4，正方形，圆角 8，垫底 light-1。
- **发现瀑布流**：间距 4，圆角 8。列数 6 / 4 / 3 / 2 / 1，对应宽度 >1440 / ≤1440 / ≤1100 / ≤700 / ≤500。
- 图片下面不放文字。悬停时：
  - 右上角（距边 12）出现操作，用 on-media 底色的 IconButton。
  - 发现页底部出现渐变和作者行：头像 16 + 12 号名字。
- 文件夹区：
  - 7 列（≥1920 时 8 列），间距 12。
  - 封面圆角 8；名称在封面下面，间距 4，14 号粗。

- **项目卡**：
  - 圆角 12，1px 描边 border，底色 light-2。
  - 上面是封面，下面是信息行，左右内边距 8。
  - 名称 14 号单行，下面是更新时间 12 号 tertiary，间距 2。
  - 悬停时卡片底色升到 light-2-hover。
- **模板卡**：外层内边距 6，封面圆角 8，名称 14 号单行。悬停时封面上盖一层黑 50%，中间出现按钮（小号 28）。

### 4. 详情页
素材详情（CardDetailModal）是全屏弹窗。

- 内边距 24 32，间距 32。
- 左边是大图或视频，右边是信息栏，宽 440。

### 5. 弹窗里的列表或市场
比如技能市场，用弹窗 L（1024）。

- 顶部选项卡 · 中。
- 卡片 2 列，间距 16。
- 卡片内边距 12，圆角 12，底色 light-2；封面圆角 8。

## 通用排法

- **间距**：
  - 页面左右边距 24，分区之间 32，区块之间 16–24。
  - 纯图片网格的间距 4；带文字的卡片 12；大卡片 16。
- **圆角**：图片和视频 8，卡片 12，大面板 16。
- **悬停操作**：图片和视频上出现的操作按钮、标签，一律用 on-media 底色（黑 40%），任何画面上都看得清。
- **长列表**：顶部筛选条吸顶。加载时用骨架屏，照网格的形状摆。
- **空列表**：用空状态（大）居中。
