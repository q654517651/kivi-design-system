# 画布

无限画布上的东西：节点、节点外框和连接点、连线、节点上方的工具栏、画布左侧工具栏、节点下方的生成面板、右键和快捷菜单。

代码里对应：`packages/infinite-canvas`（base-node、node-topbar、node-panel、line）。状态：待确认 0.1.0。

这些组件是从旧组件库原样迁过来的，状态和样式没变，只换了变量和图标。所以有几处和通用规则不一样（文字 14、节点底 #181818、菜单项 44 高）。改已有画布界面时，保持和现有画布一致；新做的画布功能，按通用规则做，并注明差异。

## 节点

- 默认 256×256，音频节点 341×256。
- 圆角 16。
- 底色 #181818（旧值，以后会统一成 surface），1px 描边 `--color-border`（白 12%）。

| 节点 | 状态 |
|---|---|
| TextNode 文字 | 引导态、待生成、生成中、完成、失败 |
| ImageNode 图片、VideoNode 视频 | 引导态、待生成、生成中、完成、失败、堆叠、鼠标悬浮、展开效果 |
| AudioNode 音频 | 引导态、待生成、生成中、完成、失败 |
| UploadNode 素材（上传） | 上传中、上传完成（视频 / 图片 / 音频） |
| VideoPackNode 视频封装、VideoCutNode 视频剪辑 | 未点击、点击态、生成中、完成 |

- **引导态**：中间是几个可选的起步方式（比如「自己编写内容」「图片反推提示词」），每项 14 号字、白 50%，悬停底色白 8%、圆角 8。
- **待生成**：中间一个 64 的类型图标。
- **失败**：文字白 50%，内边距 24。
- 每种节点的生成中、失败、引导态都各画了一份，改样式时要一起改。

## 节点外框 NodeWrapper 和连接点

- 节点上方是节点名：14 号粗、secondary，和节点间距 8。
- 左右两侧各有一个连接点 ConnectorDot，直径 16，底色 #0A0A0A，2px 描边。
  - 默认：描边白 20%。
  - 已连接：描边白 20%，中间一个 6 的白 20% 实心点。
  - 高亮：描边白 50%，中间一个 6 的白 50% 实心点。
- 悬停或选中：节点外面加一圈 2px 白 40% 描边，圆角 16。
- 节点比例：

| 比例 | 尺寸 |
|---|---|
| 1:1 | 256×256 |
| 3:4 | 256×341 |
| 4:3 | 341×256 |
| 16:9 | 455×256 |
| 9:16 | 256×455 |

## 连线 Connector

| 状态 | 颜色 | 粗细 |
|---|---|---|
| 默认 | --g-workflow-line-color-default（#424242） | 1.5 |
| 激活（悬停、点击、选中节点的关联线） | 白 55% | 2 |
| 拖拽中 | 白 35% | 1.5，虚线 6/6 |
| 执行中 | 白 90% | 1.5，加一道流光，2 秒一轮 |
| 出错 | 白 60% | 1.5 |

悬停或选中连线时，连线中点出现删除按钮 ConnectorRemove：
- 24 的圆，底色 light-1（白 8%），1px 描边 border，背景模糊 6。
- 中间是 Cutting 图标，16。

## 节点工具栏 NodeToolbar

选中节点时，出现在节点上方。

- **容器**：高 44，内边距 6，按钮间距 8，圆角 12，玻璃（#181818 70% + 1px 描边 + 背景模糊）。
  - 旧库的模糊是 32、描边白 8%。统一后改成模糊 16、描边白 12%，以玻璃规格为准。
- **工具栏按钮 ToolbarItem**：
  - 高 32，圆角 8，内边距上下 6、左右 12，图标和文字间距 8。
  - 图标 20，颜色 tertiary；文字 14，白色。
  - 内容有三种：图标加文字、纯文字、纯图标（32×32）。
  - 悬停时底色 light-1（白 8%）。
- **按节点类型分四种**：图片、文字、视频、打组。图片的包括裁剪；视频的包括抠图、剪辑、封装；工具之间可以用竖线分组。具体放哪些工具以现有画布为准。
- 裁剪图片时出现裁剪框 CropHandles：描边 2px，颜色 #4AFF70（代码里保留这个值）。

## 画布左侧工具栏 CanvasToolbar

- 竖排，宽 56，圆形胶囊（999），内边距上下 16、左右 12，图标间距 16，图标 24。
- 底色 surface，1px 描边 border-subtle，背景模糊 12。
- 内容：添加文字、图片、视频、工作流模板、剪辑、历史、上传。
- 当前选中的工具用 IconButton 的「选中」状态：品牌绿 12% 底，品牌绿图标。

## 节点生成面板 NodePanel

选中节点时，出现在节点下方。用来写提示词、放参考图、选模型。

- 宽 620–800，内边距 16，区块间距 16，圆角 12。
- 底色 surface。按 2026-10-27 定的方向，节点面板属于「选」东西的浮层，以后改成玻璃。
- 由三个区块拼成：
  - **参考图区 PanelRefs**：高 56 的缩略图条，缩略图间距 8，角上有序号；首尾帧中间用箭头连接。参考图太多时，右侧用渐变遮罩表示超长。
  - **提示词区 PanelPrompt**：14 号字，高 80，最高 120。没输入时显示占位文字，比如「描述任何你想要生成的内容」。可以用 @ 引用素材，引用会变成 MentionChip：高 17，圆角 4，白 8% 底，1px 白 8% 描边，带缩略图或音乐图标。
  - **模型选择栏 PanelModelBar**：高 36。左边是模型选择（下拉 · 无底）和比例、数量等参数；右边是生成按钮。
- 「创作页」那一种底栏是单独画的（PanelModelBarCreate）。

## 快捷菜单（模板）

右键菜单、模型选择、比例、数量、时长、分辨率、语速这些弹出菜单和小面板。

- 是模板，不是组件，照旧库当前文件原样重建。
- 菜单项 44 高、圆角 12，和新的 MenuItem（36 高、圆角 8）不一样，统一时要设计确认。
- 新做的菜单按「菜单和提示」里的菜单模板来。
