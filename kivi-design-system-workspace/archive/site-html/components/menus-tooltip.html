菜单和提示

非模态浮层：Tooltip 和菜单。底色都是 popup，不加描边、阴影和毛玻璃。菜单项、分组标题、分割线是组件；整个菜单是模板。最后是主站侧栏的三个零件。

Tooltip 是鼠标停留时的说明，移开就消失；菜单是点开或右键后选一个操作。操作结果（保存成功、生成失败）不用 Tooltip，用 Toast。

  • 菜单不是一个组件：复制「菜单模板」的容器，往里放 MenuItem、MenuLabel、MenuDivider，条目随便增删。画布右键、节点右键、模型选择、@素材、下拉选择展开的列表，都用它拼，不单独做组件。
  • 弹出菜单、Tooltip 的出现和消失动效写在 menus-tooltip.css 里，规则见「动效」页。

Tooltip

在右边面板选类型、改文字，和 Figma 右侧属性面板一样。下面的代码跟着变，可以直接复制。面板里摆的是静态的，真实的悬停出现看「用法」。

用途

鼠标停留时出现的文字提示，移开就消失。

  • 只有图标的按钮必须加 Tooltip，写清楚它是做什么的；按钮上已经有文字的不用加。
  • 有快捷键的把快捷键带上，比如「撤销 ⌘Z」。
  • 和 Toast 的区别：Tooltip 是鼠标停留才出现、移开就消失的说明；操作结果的反馈（保存成功、生成失败）用 Toast。

结构

  • 简单：一行文字，后面可以带快捷键，间距 8。
  • 说明：标题 + 一段说明，竖排，间距 4，最宽 240。
  • 不带小箭头、描边、阴影、毛玻璃。
  • 要悬停弹出，把目标和 Tooltip 一起放进 kv-tooltip-anchor；Tooltip 自己定位，出现在目标下方 8px。不放进去的 kv-tooltip 是静态的，文档摆样子用。

MenuItem

在右边面板选类型、状态和左右两边放什么。「左边二选一、右边三选一」已经写进面板规则：一边开了，同组的其他开关就灰掉。

用途

菜单里的一条。可以点，点了执行一个操作或选定一个值。

结构

左边（可选）+ 文字 + 右边（可选），水平排列，间距 8。

  • 左边放图标或缩略图，二选一。图标 16；缩略图是 AssetThumb 24，可以切图片 / 音频。
  • 右边放快捷键、子菜单箭头、勾选，三选一。
  • 文字撑满剩下的宽度。宽度在菜单里是「填满」。
  • 可以点的写 <button type="button">，文字包一层 <span>。

用法

  • 左图标：基础菜单、分组菜单，让每一项好认。什么都不放：右键菜单、比例、数量这类纯文字的选项。缩略图：@素材。

  • 选中：单选菜单里标出当前项，白 8% 底，不打勾，比如数量、比例。勾选：在右边打勾。当前项怎么标，Figma 里「选中」和「勾选」两种写法并存，详见「菜单模板」的单选例子。待确认
  • 危险：删除这类操作，放在菜单最后，用 MenuDivider 和上面隔开。
  • 禁用：条件不满足时用，比如没东西可粘贴。
  • 整个菜单的拼法见「菜单模板」。

菜单模板

容器 kv-menu 加上 MenuItem、MenuLabel、MenuDivider。Figma 里这个模板在「模板 · 通用」页「菜单」分区。

用途

下拉菜单、右键菜单、单选菜单、素材菜单。下拉选择展开的列表也是它，宽度和触发器一样宽。

结构

  • 容器：底色 popup，圆角 12，内边距 4，条目之间不留空。
  • 里面放条目：MenuItem、MenuLabel、MenuDivider，数量和顺序随便。
  • 菜单不是组件：条目写死在组件里，加一项就要改组件或解绑，所以用模板拼。
  • 子菜单：点了会再弹出的项，右边放子菜单箭头；弹出来的也是一个菜单模板。

SidebarItem

下面三个组件是主站侧栏的零件，不是菜单。整条侧栏是模板，在「模板 · 主站」页，主站页里会用到它们。

用途

主站侧栏的一项。「导航」是固定入口，比如新建；「列表」是历史记录，对话和画布。

结构

  • 导航：左图标 20 + 文字，文字和图标都是 primary。
  • 列表：左边缩略图（AssetThumb 24）+ 文字；文字默认 secondary，悬停、选中变 primary。有封面的选「图片」；没封面的选「图标」，对话用 Message，画布用 Canvas，不要直接放裸图标。
  • 右边可以有「更多」：IconButton 28 弱，More 图标，点了单独弹一个菜单；悬停和选中时才显示。
  • 带「更多」时外层用 <div>，不要把按钮放进 <button> 或 <a> 里。
