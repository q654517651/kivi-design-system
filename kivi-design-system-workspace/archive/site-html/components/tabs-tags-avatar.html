TabItem

一个组件管两种用法，用「样式」切换：选项卡切换下面整块内容，分段在一条底槽里选一个参数值。在右边面板选属性，和 Figma 右侧属性面板一样。面板调的是第一项，另外两项是陪衬。

用途

  • 选项卡：切换下面整块内容，比如「全部 / 收藏」「图片 / 视频」。
  • 分段：在一条底槽里选一个参数值，比如比例、分辨率。

切换内容用选项卡，选一个参数值用分段，两个不要混。

结构

一项 = 左图标（可选）+ 文字。一组里同一时间只有一个选中。

  • 选项卡 · 横排：左图标（可选，16）+ 文字，间距 6。没有底槽，一组选项卡之间间距 4。
  • 分段 · 横排：只有文字，没有左图标。放进底槽，选项设成「填满」，平分宽度。
  • 分段 · 竖排：图标 20 在上，12 号字在下，间距 4，56 × 56。只有分段、中号用，比如比例选择。
  • 一组放进 kv-tab-group；分段的底槽是 kv-tab-group--segment：内边距 4、圆角 12、底白 8%。这两个来自「模板 · 通用」页，不是组件。待确认
  • 选项卡：一组放进 role="tablist"，每项 role="tab"，选中用 aria-selected="true"。对应的内容区用 role="tabpanel"，用 aria-controls 连上。
  • 分段：选的是一个值，不是换一块内容，所以用 role="radiogroup"，每项 role="radio"，选中用 aria-checked="true"。
  • 选中的一项 tabindex="0"，其他 -1；左右方向键移动选中。库里不带脚本，演示里有写。

Tag

在右边面板选类型、缩略图、左图标。

用途

展示参数、状态这类短信息，不能点。盖在图片、视频上的角标（时长、序号、4K）也是标签，用「覆盖」类型。旧的各种 badge 都并到这里。

结构

缩略图（可选）+ 左图标（可选）+ 文字，水平排列，间距 4，左右内边距 6。

  • 缩略图 16，圆角 2，放参考图。
  • 左图标 16，比如模型 Logo；换图标在里面换。
  • 任务角标 = 覆盖 +「59s 生成中」，不带图标。

Avatar

在右边面板选类型、尺寸。

用途

圆形的用户头像。没有头像图时，显示用户名首字。会员头像框是运营装饰，不放进组件。

结构

  • 图片：圆形，图片铺满，加载前垫白 8%。
  • 文字：圆形底，中间一个首字。
  • 头像和名字的间距 8。

AssetThumb

在右边面板选类型、尺寸。

用途

素材的小预览。图片和视频首帧放图；音频用统一的渐变底加音符；没封面时用「图标」占位。

结构

  • 图片：图片铺满。图片、视频首帧都用它。
  • 音频：渐变底 + 居中的音符（Music）。
  • 图标：白 8% 底 + 居中的图标，图标不透明度 30%。图标可换：对话用 Message，画布用 Canvas。
  • 三种类型都有 1 的内描边。
  • 序号、时长这类角标由外层叠加，不放进来。

属性

尺寸16 / 24 / 56 / 72kv-asset-thumb--16 / --24 / --56 / --72，16 是默认
图缩略图的图片图片类型里的 <img>（alt=""）
图标音频固定 Music；图标类型可换<i class="kv-icon" data-icon="名字">

没有悬停、按下、禁用状态。

用法

  • 图片：图片、视频首帧。音频：音频条目。图标：没封面时占位。
  • 外层组件（MentionChip、MenuItem、ReferenceItem 等）已经暴露「类型」，直接切图片 / 音频 / 图标。
  • 在 Figma 里换图：选中缩略图改填充；换占位图标：选中里面的图标换。
  • 图标类型的颜色用图标图层的不透明度，不改图标本身的填充，换图标后颜色仍跟着组件走。
