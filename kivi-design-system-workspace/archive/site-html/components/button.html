Button

在右边面板选尺寸、类型、状态，和 Figma 右侧属性面板一样。下面的代码跟着变，可以直接复制。

用途

带文字的按钮，点了做一个动作。

结构

左图标（可选）+ 文字 + 右图标（可选），水平排列，间距 4。

  • 左图标跟按钮高度走：小 16，中、大 20。
  • 右图标是下拉箭头，固定 16。
  • 文字包一层 <span>，「弱」要靠它整体调透明度。

类型和状态

悬停、按下在这里摆成静态的，方便对照；鼠标移上去也能试。

  • 底色变化 100ms ease-in-out，见「动效」。

用法

  • 主要：生成、确认、提交。一屏只放一个。「生成」也用普通的主要按钮，不做胶囊，保持品牌渐变。
  • 次要：取消和普通操作，最常用。
  • 文字：工具栏里的操作、不需要强调的操作，比如节点工具栏、输入框下面的工具条。
  • 危险：删除这类不能撤销的操作，在确认时把主要按钮换成危险按钮。
  • 浮层：盖在图片、视频上，比如节点完成态的「设为封面」、生成中的倒计时。
  • 弱：内容区里不想抢眼的操作，比如生成记录底部、Agent 回复底部。
  • 尺寸：小用在顶栏、卡片上的小操作、紧凑的工具条；中是默认，节点工具栏、输入框下面的工具条、面板里的操作；大用在弹窗底栏、表单提交、页面上的主操作。
  • 禁用：条件不满足时用。加载中：点击后等结果时用。

IconButton

用途

只有图标的按钮，点了做一个动作；也用来做有开关状态的工具，比如加粗。

结构

正方形，中间一个图标。图标本身不加背景和内边距，底色和点击区域由 IconButton 提供。

属性

属性选项代码
尺寸28 / 32 / 36kv-icon-button--28 / --32 / --36，32 是默认
类型主要 / 次要 / 文字 / 浮层 / 弱--primary / --secondary / --text / --on-media / --weak
状态默认 / 悬停 / 按下 / 禁用 / 选中禁用 disabled；选中 aria-pressed="true"
图标图标库里的任意图标<i class="kv-icon" data-icon="名字">
  • 「弱」只有 28、32 两档。
  • 主要和弱没有「选中」。
  • 只有图标，必须写 aria-label 说明它是做什么的。

  • 各类型的底色、图标颜色和悬停、按下、禁用，都和 Button 同名类型一样（图标颜色对应 Button 的文字颜色）。
  • 选中：底色 brand/subtle（品牌绿 12%），图标 brand/solid。浮层类型选中时底色是 on-media/fill-hover（黑 60%），图标同样是 brand/solid。

用法

  • 28：顶栏、卡片上的小操作。侧栏收起、分组新建、列表「更多」用弱。
  • 32：默认。节点工具栏、底部工具条、输入框里的操作。Agent 消息操作用弱。
  • 36：和大按钮并排时，比如输入框的发送。
  • 主要：发送、生成。
  • 选中：只给有开关状态的工具用，比如文字工具栏的加粗、工具栏里当前选中的工具。
  • 只有图标的按钮都要配 Tooltip，说明它是做什么的。
