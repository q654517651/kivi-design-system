Input

在右边面板选状态、左图标、字数，和 Figma 右侧属性面板一样。预览里的输入框也能打字。

用途

单行输入：搜索、改名、表单。

结构

左图标（可选）+ 输入的文字 + 字数（可选），水平排列，间距 8。外面是一个 <label>，点框的任何地方都能输入。

  • 占位文字和输入内容是同一个 <input>：没内容时显示 placeholder，有内容显示内容。
  • 左图标固定 16，比如搜索框用 Search。
  • 字数放在框内右侧，比如「0/50」。
  • 宽度在使用时设成填满（默认 width: 100%）；Figma 里摆的是 240。
  • 没有可见文字标签时，必须在 <input> 上写 aria-label。

用法

  • 搜索、改名、表单里的单行输入用它。只输入数字的用数字输入框。
  • 搜索框：左边放 Search 图标，宽度填满。

  • 表单行是模板（Figma「模板 · 通用」页「表单」）：标签 13 号 secondary 在上，间距 8；提示 12 号 tertiary 在下；出错时提示换成 danger 色。

NumberInput

用途

输入一个数值，可以带单位，比如时长「12 秒」。只输入数字的地方用它，不用普通输入框。

结构

数值 + 单位（可选），水平排列，间距 4，居中。宽度跟着内容走，最小 64。

  • 范围有限、要拖着调的，左边配一个滑块（见「选择控件」页 Slider）。
  • 用文字输入框加 inputmode="numeric"，不用 type="number"，免得出现上下小箭头。只允许数字要自己接。
  • 没有可见标签时，必须在 <input> 上写 aria-label。

Select

在右边面板选样式、状态，和 Figma 右侧属性面板一样。预览里的下拉也能点开、选值。

用途

点开后从列表里选一个值。「填充」用在表单和面板里；「无底」用在工具条上，比如输入框里的模型选择。

结构

Select 只是触发器：左图标（可选）+ 文字 + 右箭头，间距 4。展开后的列表是菜单模板（kv-menu + kv-menu--popup）+ MenuItem（kv-menu-item），见「菜单和提示」页。

  • 外面包一层 kv-select-wrap，列表放在触发器后面，由它定位。无底样式加 kv-select-wrap--plain。展开时触发器写 aria-expanded="true"，列表加 is-open。
  • 左图标 16，右边是 16 的小箭头 DownArrowSmall；展开时换成 UpArrowSmall（换图标，不是旋转）。
  • 文字没选时是占位文字，选了是选中的值。
  • 列表宽度和触发器一样宽；单选时给当前项打勾：role="menuitemradio" + aria-checked="true"，右边放 kv-menu-item__check（CheckSmall）。
  • 选项只有 2–6 个、而且一眼能看完的，用分段选择器，不用下拉。

Textarea

在右边面板选状态、字数，和 Figma 右侧属性面板一样。预览里的输入框也能打字，右下角可以拖着改高度。

用途

输入一段话：描述、备注。14 号字，是需要阅读的内容。

结构

输入的文字在上，字数在右下角，垂直排列，间距 8。外面是一个 <label>，点框的任何地方都能输入。

  • 默认 320 × 104，可以拉伸；使用时宽度设成填满（默认 width: 100%），高度可以拖。
  • 占位文字和输入内容是同一个 <textarea>。
  • 字数放在右下角，和正文间距 8。
  • 提示词输入用画布页的 PromptInput；首页、对话里的整块输入区是模板，见下面「提示词输入框」。
