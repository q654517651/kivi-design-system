GenPrompt

在右边面板选长度、开关，和 Figma 右侧属性面板一样。鼠标移到参考区上，下面会弹出浮层显示全部参考素材。

用途

主站生成记录的头：一条记录最上面那块，显示时间、提示词、参数。

结构

垂直排列，间距 4：时间（可关）+ 提示词 + 参数（一排 Tag，间距 6，放不下换行）。

  • 提示词：短的在一行内，复制按钮紧跟在文字后。超出两行的最多 2 行，末尾省略；复制按钮放在第二行行尾，左边 40 的渐变从透明过渡到底色，盖住被截断的文字。
  • 参数：任务类型（Tag 带左图标：图片生成 / 视频生成 / 音频生成；工具类直接写工具名，比如抠图、扩图、视频拼接）· 参考区 · Tag 1–3（Lora 带缩略图、清晰度、比例、时长、语速、音调…）· 模型（左图标 + 模型 Logo）。
  • 参考区：所有参考素材放一块，图片、视频（首帧）、音频可以混排，原图、原视频也放这里。图在前，后面跟参考方式文字（首帧 / 首尾帧 / 全能参考 / 参考图 / 原图…）。
  • 帧率、张数、生成音频都不展示；没有图生图、控制图、ControlNet。

待确认 参数的顺序。Figma 的说明文字写「任务类型 · 参考区 · Tag 1–3 · 模型」，但组件和「模板 · 主站」里实际画的是「任务类型 · 模型 · 参考区 · Tag 1–3」。下面的示例按画出来的排。

组件里摆的是最全的情况（生视频），用的时候把不要的 Tag 隐藏、改文字，不另做变体。各种情况的摆法见「模板 · 主站」的「参数全集」。

ResultTile

在右边面板选类型和状态。鼠标移到完成的格子上也会出操作。

用途

主站生成结果的一格：一条记录里的一张图或一段视频。每格的任务独立：各自生成、完成或失败。画布 Agent 不用它，用 NodeCard。

结构

一个方块，里面叠放：画面 + 左上任务角标（生成中）+ 右上操作 + 左下快捷操作（悬停才出）。视频完成时左下是时长，悬停时底部出播放条。

  • 快捷操作的最后一个是「更多」。
  • 任务角标 = Tag 覆盖，只有文字。
  • 没有排队状态。

属性选项代码

画面图片、视频首帧<img class="kv-result-tile__media">

矩阵里缩成 184 宽方便并排，规格是 256。

用法

  • 一条记录的结果网格里，每一格一个 ResultTile。每格各自生成，所以一条记录里可以同时有生成中、完成、失败的格子。
  • 快捷操作按代码现有的排：图片常显「图片编辑、图生视频、一键垫图」，高清修复、一键抠图、一键扩图、添加文件夹收进「更多」；视频常显「视频编辑、视频高清、视频循环」，视频拼接收进「更多」。待定 哪些常显。
  • 失败时消耗的猕猴桃已退回，所以文字里直接写。
