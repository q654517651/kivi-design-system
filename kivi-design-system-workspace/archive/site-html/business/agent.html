不是组件的部分

顶栏、整段对话、输入框都是模板，在「模板 · 画布 Agent」页的「侧栏 Agent」。生成中和完成的节点直接用画布页的 NodeCard，不在这一页。

  • 助手回复没有气泡，直接用正文字号（14 / 22，primary）。
  • 建议操作：Button 中 · 次要。消息操作：IconButton 32 · 文字。都在模板里拼，不单独做组件。
  • 引用画布内容走右键「发送到对话」，进到输入框的引用条，不做选中即引用。
  • 面板外框、内边距和输入框取同一个值，待定 输入框圆角。

ProcessRow

在右边面板选层级、状态、展开，和 Figma 右侧属性面板一样。进行中的动作文字带扫光。

用途

Agent 过程行：一行显示思考、调工具、询问、生成。类型不靠属性，靠图标和文字区分：

类型图标文字
思考关掉图标，打开头像「Agent 思考中」。只在 Agent 内部思考、还没返回内容的空档出现
工具UseCanvas / Skill「创建节点 活动标题」。连续调用折叠成「调用了多个工具」，打开箭头
询问Message「询问中 / 已询问」。展开后看问题和回答
生成ImageGeneration「图片生成中 / 图片已生成 × 5」
汇总关掉图标「已完成」

待梳理 工具调用的状态用词（询问中 / 已询问、使用中 / 已使用等）还没统一，先照 Figma 现在的写，之后统一梳理。

结构

一行，水平排列，间距 4，垂直居中：图标（可选）+ 头像（可选）+ 动作文字 + 对象文字（可选）+ 箭头（可选）。

  • 动作文字是主体，对象文字是它作用的东西，比如「创建节点」+「活动标题」，颜色比动作淡一档。
  • 一级可以带头像和箭头。子项（展开后列表里的行）没有头像和箭头，也不能点。
  • 展开后的列表和一级用同样 20 的图标，不缩进（参考 Codex）。

UserMessage

用途

用户消息：气泡靠右，宽度跟文字走，超出换行。可以带素材。

结构

垂直排列，间距 8，整体靠右：素材行（可选）+ 气泡。

  • 素材行是一排 ReferenceItem 56，间距 8。图片、带时长的视频、音频都放这里。
  • 组件宽 428，放进模板里拉满。

素材无 / 有有就放 <div class="kv-user-message__assets">，里面是 kv-reference-item（ReferenceItem 56，缩略图用 kv-asset-thumb--56）

样子

部分规格
气泡底色container-light-1（白 8%）
气泡圆角12 · --border-radius-md
气泡内边距12 / 16 · --spacing-md、--spacing-lg
气泡文字14 / 22 常规，primary；最宽 340，超出换行

  • 用户发的消息都用它。带图片、视频、音频时用「素材 = 有」。

QuestionPanel

Agent 需要用户回应时，停在输入框位置的面板：QuestionPanel（追问，选项用 _QuestionOption）、ActionCard（生成确认；授权和出错放在消息里）。外框和输入框一致。

用途

追问面板：Agent 追问时停在输入框的位置，替换掉输入框。答完后消息里留一行 ProcessRow「已询问」。

结构

垂直排列，间距 12：题目栏 + 选项 + 底部操作。

  • 题目栏：题目（14 粗）+ 分页（多道题时显示「1/5」，左右切换）。
  • 选项：_QuestionOption，单选时只有一项选中，多选可以选多项。选项间距 4。
  • 「其他」一项可以直接输入。
  • 底部：忽略（Button 中 · 文字）+ 确认提交（Button 中 · 主要），靠右，间距 8。

属性

属性选项代码
题目文字，默认「1. 你喜欢小猫吗？（2 个选项）」.kv-question-panel__title
显示分页开 / 关，默认开放不放 .kv-question-panel__pager
分页文字，默认「1/5」pager 里的文字，两边是 IconButton 28 · 文字（LeftArrowSmall、RightArrowSmall）
显示其他输入开 / 关，默认开放不放 kv-question-option--other 那一项
显示忽略开 / 关，默认开放不放「忽略」按钮

样子

部分规格
外框底 surface，描边 border-subtle 1，圆角 16 · --border-radius-lg，内边距 16 · --spacing-lg
题目14 / 22 粗，primary
分页文字13 / 20 常规，secondary；和两个按钮的间距 4
  • 外框和输入框取同一个值：surface 底、border-subtle 描边、圆角 16、内边距 16。待定 输入框圆角。

用法

  • Agent 追问时用，停在输入框位置，替换掉输入框。
  • 单选的题，点一项就选中它、取消另一项；多选的题可以选多项。
  • 「忽略」是跳过这道题，「确认提交」是提交答案。

ActionCard

用途

确认卡片，三种：生成确认（停在输入框的位置）、授权和出错（在消息里）。

结构

垂直排列，间距 12：文字（标题 + 说明，间距 4）+ 操作（靠右，间距 8）。出错只有一行说明。

属性

属性选项代码
类型生成确认 / 授权 / 出错生成确认、授权用默认；出错加 kv-action-card--error
标题、说明直接改文字.kv-action-card__title、.kv-action-card__desc；说明里可点的一段用 .kv-action-card__link
显示次按钮开 / 关，默认开放不放「取消」；只有生成确认有
按钮文字改按钮里的文字kv-button kv-button--md，次要「取消」、主要「确认生成」/「去授权」

样子

类型外框内容
生成确认底 surface，描边 border-subtle 1，圆角 16，内边距 16标题 14 / 22 粗 primary；说明 13 / 20 tertiary；取消（次要）+ 确认生成（主要）
授权同生成确认标题 + 说明 + 去授权（主要）

  • 生成确认的说明里「点击查看节点参数」带下划线，颜色同说明。
  • 确认生成按钮上的猕猴桃消耗数 待定：Figma 里还没补，等猕猴桃图标定了再加。

用法

  • 授权：读取飞书文档这类需要用户授权时，放在消息里。
  • 出错：服务异常时放在消息里，说明本次是否消耗积分。
