时长：按动多远选

时长变量用在哪
100ms--motion-duration-100只换颜色：悬停、按下的底色和文字颜色
150ms--motion-duration-150小东西出现、消失：Tooltip、删除按钮、角标、开关滑块
200ms--motion-duration-200移动 100px 以内；菜单、下拉列表、Toast 出现
300ms--motion-duration-300移动 100–400px：参考区展开收起、面板展开收起、弹窗出现
400ms--motion-duration-400移动 400px 以上，或整屏：侧栏、抽屉滑进滑出
  • 消失比出现短一档：菜单出现 200ms，消失 150ms。
  • 最长 400ms，再长就拖了。
  • 几样东西依次出现时，每个错开 20–30ms，整体不超过 400ms。
  • 悬停触发的展开，鼠标离开后等 150ms 再收起，免得划过时来回闪。
  • 系统开了「减少动态效果」时，去掉位移和缩放，只留透明度，或者直接切换。tokens.css 里已经把时长归零。

写法

出现和消失的缓动不同时，把消失的写在默认状态上，出现的写在出现后的状态上。

    .menu {
      opacity: 0;
      transition: opacity var(--motion-duration-150) var(--motion-ease-in);
    }
    .menu.is-open {
      opacity: 1;
      transition: opacity var(--motion-duration-200) var(--motion-ease-out);
    }
