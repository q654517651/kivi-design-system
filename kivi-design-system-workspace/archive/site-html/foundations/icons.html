一套 24×24 的线性图标，全部转轮廓。设计、产品、研发用的是同一套图标、同一个名字。要用图标，先在下面的「图标表」里按意思找。

规格

项规格
框和图形组件框 24×24，图形缩到 22，居中，四边各留 1。名字带 Small 的图标，图形缩到 18。
线宽1.5
形态发布用的是转轮廓、合并后的版本。Figma 里另外留一份能改线宽的描边版，在「_源文件 · 图标描边」页。
名字英文大驼峰，按意思起，比如 Close、OneClickSameModel。Figma 组件名、字体类名 icon-kivi-名字、代码里 Icon 的 name、kivi/icons.js 的 data-icon 用同一个名字，区分大小写。
背景和内边距不加。要底色和点击区域，就放进 IconButton。

尺寸

尺寸用在哪
16（默认）按钮、菜单、输入框里
20工具栏、面板标题、弹窗关闭
24大入口、竖向工具栏
40 / 64空状态、大入口插图位
  • 尺寸由外层容器决定，图标按比例缩放。不为每个尺寸单独画图。
  • 40 和 64 是整体放大，线条会跟着变粗（40 约 2.5px，64 约 4px），和旧版 iconfont 放大的效果一样。

一个图标只有一个意思

不要拿意思相近的图标顶替。专用规则：

  • Agent（大号星星）只给 Agent 用；其他 AI 功能用「素材 + 小星星」类的图标。
  • FirstLastFrame（胶片）只给首尾帧用；「视频」用 Video。
  • 文本节点用 Text；字号设置用 FontSize。
  • 思考过程用 Lightbulb；工具调用用 Tool。

画法

新画的图标，不管是设计师画进 Figma，还是原型里临时画，都照下面这几条，和库里的图标放在一起才不突兀。

Lucide 的规格

  • 在 24×24 的网格上画，四边至少留 1。
  • 线端是圆头，转折是圆角；只描边，不填充。
  • 矩形圆角：边长 8 以上用 2，小于 8 用 1。
  • 分开的两个部分之间至少留 2。

KIVI 的调整

  • 画好后等比缩到 22，再把线宽改回 1.5。

从库里已有图标提炼的写法

  • 内容类（文本、视频、图片）：一个圆角方框，里面放一个认得出的符号，比如 T、播放三角、山形。参考 Text、Video、ImageToText。
  • AI、生成类：在主体的一角加一个小四角星，星和主体之间断开留缝。参考 ImageGeneration、VideoGeneration、AIEnhancement。大号四角星只给 Agent。
  • 关闭、隐藏类：在原图标上加一条斜线，斜线两边留缝。参考 DisableSnap、HideConnections。
  • 多份、批量：两层叠放，后面一层只露出一部分。参考 ImageToImage、OneClickSameModel。

怎么加新图标（设计）

图标表里没有合适的，按下面的步骤加。不要拿意思相近的旧图标顶替。

  1. 去 Lucide 找：
    • 静态图标：lucide.dev/icons
    • 动态图标：lucide-animated.com
  2. 下载：按 24px、线宽 1.5 下载 SVG。
  3. 缩放：等比缩到 22，居中放进 24×24 的框，四边各留 1。缩完把线宽改回 1.5，不要跟着缩成 1.375。
  4. 放进 Figma（KIVI UI KIT V2）：
    • 描边版放进「_源文件 · 图标描边」页，留着以后改。
    • 转轮廓、合并后做成组件，放进「图标」页对应的分组，按上面的规则起名。
    • 组件描述照下面的格式写。
    • 把它加进 Icon 组件里「图标」属性的首选值，之后在 Icon 实例里才选得到。
    • 在图标页的展示格里写名字和备注，备注的颜色见下面。
  5. 标「待确认」：新加进 Figma 的图标，不管是谁加的，都先标「待确认」：描述里加一行「状态：待确认（用在哪）」，备注用橙色。设计师确认后才转为正式图标。
  6. 补到本页的图标表里：写名字、意思、备注。之后重新导出 kivi/icons.js。
    关键词：发送 提交 上箭头
    来源：lucide/arrow-up · 缩到 22/24 · 线宽 1.5，已转轮廓

  • 名字用下面图标表里的名字，区分大小写。
  • 字体只能单色。Logo 有两种颜色，字体里怎么放，待定。
  • 旧名（Mdoel、Snap1 等）在字体里留别名，见「旧名对照」。
  • 图标表里没有的，不要自己去网上找，也不要用意思相近的顶替。在交付里写「缺图标：××（用在哪）」，交给设计按上面的步骤加。

网站和原型里

引用不了字体的地方（这个网站、HTML 原型），用 kivi/icons.js，名字和上面一样。

    <i class="kv-icon" data-icon="Close"></i>

    <script src="kivi/icons.js"></script>
    <script>KiviIcons.render();</script>
  • 图标表和 icons.js 里都没有合适的：原型里可以自己画（也可以让 AI 画）一个 SVG，照「画法」，viewBox="0 0 24 24"、stroke-width="1.5"、stroke="currentColor"、fill="none"。在原型备注里写「临时图标：××」。
  • 临时图标只能留在原型里。要进 Figma 和代码，得交给设计师按上面的步骤做。

图标表

按 Figma 的分组排。点名字复制名字。备注里的「自绘」是图标库里没有、按旧图标重画的；待确认 是 Figma 里标了待确认的。
