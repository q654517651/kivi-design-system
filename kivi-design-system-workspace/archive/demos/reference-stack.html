交互说明

状态 / 动作什么时候数值表现
空没有参考素材72，圆角 8只有添加格，点一下上传，也可以把文件拖进输入框
一个只有 1 个素材卡片 72；+ 24 圆卡片正放不叠；右下角挂圆形 +，继续添加
收起（叠放）2 个及以上，鼠标不在参考区卡片 48；转角 −4° / 6° / 12°；+ 24 圆三张转完都收在 72×72 里，右边和文字留 12：最上面是最后加的那张，靠左下；后面两张往右上错开露出来，其余藏起来；底部写最上面那张的名字
悬停展开鼠标移到参考区，或用键盘聚焦卡片 72，间距 6；展开、收起 300ms ease-in-out；离开 150ms 后收起向右排成一排：添加格在最前，后面按添加顺序排；浮在提示词上，不把文字往下推
盖住文字展开时底色同输入框；右边留 12，再接 40 渐隐；出现 150ms ease-out，收起时等卡片收完再 150ms ease-in 消失被盖住的那几行字整行藏起来，不切半行；右边的字慢慢透出来，不和卡片贴着
名字展开时按类型分别编号每张底部写「图片1 / 视频1 / 音频1」，和提示词里 @ 引用一致；视频、音频左上角标时长
超出展开后超过输入框宽度—横向滚动，不换行；渐隐挪到参考区里面右边，提示还能往右滚，滚到头渐隐消失
上传中素材还在上传黑 40% + 进度环 28卡片盖一层暗色，中间进度环和百分比；上传完自动去掉
删除 / 预览展开后悬停某一张待确认右上角出删除（演示里已经做了）；点卡片看大图

时长和缓动按 UI 规范「动效」：屏幕内移动 ease-in-out，出现 ease-out，消失 ease-in；时长按移动距离分 100 / 150 / 200 / 300 / 400ms 五档。在手机上没有悬停：点一下参考区展开，再点一下收起。演示里的缩略图是色块，不是真实素材。
