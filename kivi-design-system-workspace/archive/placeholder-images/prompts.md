# 占位图提示词存档

`kivi-design-system/assets/placeholders/` 里 35 张图的提示词，补图或重出时用。2026-10-28 用 KIVI 的 Nano Banana 2.1（`nano-banana-2.1`）出，1K。

- 下面是 3:4 版的提示词。出 1:1、16:9、9:16 时，末尾加一句「满版出血，画面四周不留任何边框、白边、留白框和卡纸。」
- 容易画成海报样机的（晶莹猕猴桃、光影线条、IP 猕猴桃堆），开头再加「这张图本身就是满版画面，不是海报的照片或样机：不要灰色背景、墙面、桌面，不要把海报摆在背景上，不要多张并排。」，并把「海报」「招贴风格」去掉。
- 有大字 KIVI 的，末尾加「大字“KIVI”整张图只出现一次，四个字母完整连在一起，不要重复、不要拆开、不要出现其他大字和年份数字。」
- IP 的几张要带参考图（`image_reference`）：https://kivi-ai.micoplatform.com/data/image/1793192835083-5881ea29-9e44-4963-b9f6-bdbb9c29200b.jpg
