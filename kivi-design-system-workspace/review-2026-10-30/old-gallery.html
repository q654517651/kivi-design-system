通用零件（库里没有）

日历 / 日期范围

用在哪：时间筛选、历史资产、我的资产页

能凑出：Input 做两个日期框，Select 做「全部 / 最近一周…」下拉。缺：月历面板（年月切换、星期行、选中日、日期范围高亮）。

级联子菜单

用在哪：画布快捷添加节点里的「增长工具 >」；组工具栏的「布局」

能凑出：MenuItem 有右侧子菜单箭头。缺：点了不能展开，没有二级菜单的出现位置、展开时机和关闭规则。

两行菜单项（含菜单内分类、底部操作）

用在哪：技能面板、斜杠技能菜单

能凑出：Menu 外壳和单行 MenuItem。缺：标题加描述的两行条目、悬停才出现的右侧「详情」按钮、菜单顶部分类标签、底部固定的「管理 / 创建」。

搜索框

用在哪：我的资产页筛选条、素材库、技能

能凑出：Input 加一个放大镜图标。缺：专门的搜索框规格（高度、宽度、清除、聚焦态）。

拖拽上传区 / 上传格

用在哪：视频封装、创建技能封面、上传控件

能凑出：Dialog、Tag、ReferenceItem 的外壳。缺：虚线上传区（拖入高亮、格式提示）、上传后预览格（替换 / 删除）、「上传文件」下拉按钮。

文件树

用在哪：技能详情、创建技能

能凑出：Menu 的单行条目。缺：树形列表（展开箭头、缩进、文件夹 / 文件图标、选中底色、悬停「…」菜单、滚动条）。

小确认气泡（锚在按钮上）

用在哪：画布整理后「是否保留此次整理结果？」

能凑出：Dialog 的文案和按钮。缺：不带遮罩、贴在触发元素上方的轻量确认气泡。

横幅提示（警告）

用在哪：视频封装不合规提示

能凑出：Toast 的图标加文案。缺：常驻不消失的黄色警告条，可放多行，嵌在面板里。

进度环、状态徽标

用在哪：编辑历史、任务列表

能凑出：节点上传中的转圈。缺：列表行里的进度环、完成对勾、警告叹号这套状态徽标，以及行的悬停删除。

批量选择态 + 批量操作条

用在哪：我的资产页「批量编辑」

能凑出：Checkbox、AssetThumb。缺：进入批量后的选中角标、全选、底部或顶部操作条。旧稿里只画了「批量编辑」按钮，选中态是隐藏层，没有画出来。

色块选择

用在哪：组工具栏的背景色

能凑出：Tag、Switch 的圆角小块。缺：一排圆形色块（选中描边、悬停），以及它的弹出位置。

尺寸输入（宽 × 高 + 锁比例，带单位后缀）

用在哪：图片裁剪、视频导出

能凑出：Input、Slider（只有刻度版）、Checkbox。缺：宽高成对输入、中间的锁比例按钮、数值后缀（PX、S、FPS）、比例下拉和确定按钮连成的裁剪条。

筛选胶囊组

用在哪：工作流分类（全部 / 礼物 / 视觉 …）

能凑出：Tabs 的分段样式。缺：不带底槽、每个胶囊独立悬停 / 选中底色的横排版式。

分步引导

用在哪：画布新手引导

能凑出：Button、Tooltip。缺：整页引导态、步骤条（第 1/2 步 + 跳过 + 下一步）、左下角帮助气泡。

画布零件：缩放条、小地图、框选框

用在哪：画布左下角、拖拽框选、标注

能凑出：IconButton。缺：缩放条（图标 + 百分比 + 加减，带整理确认）、小地图缩略块、拖拽框选的半透明绿框。

正文排版（Markdown）

用在哪：技能详情、Agent 回复

能凑出：普通文字样式。缺：一套正文排版规格（标题、段落、列表、缩进、代码、间距）。

业务模板（用零件拼）

技能面板 / 商城 / 创建技能

用在哪：输入框里的技能菜单、技能商城、我的技能、创建技能

能凑出：Dialog、Tabs、EmptyState。缺：两行菜单项、文件树、上传区、Markdown 排版（见通用零件）。

我的资产页

用在哪：顶部导航「我的资产」

能凑出：AssetThumb 网格、Tabs。缺：文件夹卡片、搜索框、时间筛选、批量编辑。

历史资产弹窗

用在哪：画布底部「历史」、按时间筛选

能凑出：Dialog、Tabs、AssetThumb。缺：按日期分组的标题、时间筛选下拉与月历、「收藏」筛选胶囊。

视频封装

用在哪：导出为礼物、麦圈、背景封装

能凑出：Dialog、Input。缺：左侧类型列表、上传区、警告横幅、「静态 / 视频」切换。

组工具栏

用在哪：画布里选中一组节点后的顶部工具栏

能凑出：按钮条的外壳。缺：带文字的工具栏按钮、「布局」级联菜单、背景色色块、组的彩色底和标题。

标注评论

用在哪：图片节点上框选区域添加评论

能凑出：Input、Tag。缺：框选标注模式条、框 + 编号气泡、评论输入卡（发送 / 添加到对话 / 更新 / 删除）。

分享 / 预览条

用在哪：画布分享、只读预览

能凑出：Toast、Tooltip、Menu。缺：分享链接浮层与复制反馈、预览模式顶栏（头像 + 标题 + 克隆 / 应用到画布 + 关闭）。

工作流卡片

用在哪：官方工作流、保存为工作流

能凑出：Dialog、Tabs、Input、Button。缺：工作流卡片（悬停出「查看 / 应用 / 删除」）、筛选胶囊组、封面上传。

模型选择

用在哪：图片生成选模型、Lora 模型

能凑出：Dialog、Tabs、Select。缺：大图卡网格（选中绿框、右上角收藏星）、「全部类型」下拉。

查看详情

用在哪：结果图放大预览，右侧提示词、模型、参考图

能凑出：Dialog、Tag、ReferenceItem。缺：左图右信息的整页布局、缩略图条、模型卡与 Lora 卡。

左侧面板

用在哪：画布左侧：素材库、画布资产、Pinterest；全局侧栏

能凑出：Tabs、AssetThumb。缺：瀑布流素材、侧栏图标条、可收起的全局侧栏。

音色选择

用在哪：音频生成：模型下拉、音色列表

能凑出：Menu、Select。缺：带试听播放键的音色行、滚动条。

库里没有，也不建议做进通用库：画笔工具条（大小条等）、蒙版绘制和落笔后的节点生成，当业务组件单独做。
